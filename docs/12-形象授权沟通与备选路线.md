# 授权沟通与备选路线

> 版本 v1.0 · 2026-10-25
> 配套：`docs/11-主题与AI形象版权边界.md`（法律分析）、`design/05-主题与小形象规范.md`（实现方案）
>
> 本文解决一个问题：**我想用鲸鱼娘做主题形象，怎么才合法？**

---

## 0. 先明确三种场景

| 场景 | 你实际在做什么 | 风险 | 建议 |
|---|---|---|---|
| **自己用** | 装在自己手机上，只自己看 | 🟢 基本无风险 | 直接做，不用管 |
| **给几个朋友装** | 朋友用你的 Apple ID 名额（免费签名最多 3 台） | 🟡 灰色，实际风险低 | 做，但别发到公开群 |
| **公开发布** | GitHub 开源 / 发论坛 / 发 B 站 | 🔴 明确侵权 | 必须拿授权，或走方案 A/D |

**作者声明原文**（`aigengtu.com` 百科页逐字）：
> 形象版权归各自创作者：上善无形已于 2026 年 8 月 2 日声明「溟月」以 **CC BY-NC-SA 4.0** 协议开放二创（须署名、非商用、相同方式共享），ZipZipPipe 随后声明其女仆鲸鱼娘作品**禁止商用**——均以创作者原始声明为准，本站不代为授权。

关键词是 **禁止商用** + **非商用**。而 CC 官方对 NonCommercial 的定义是「**not primarily intended for or directed towards commercial advantage or monetary compensation**」——看的是「主要意图」，不是「收不收钱」。所以**公开发布免费软件也可能构成商用**（因为它在推广一个产品）。

## 1. 方案 A：只用几何符号（**零风险，已实现**）

- 8 个纯几何符号：鲸尾 A / 鲸尾 B / 四角星 / 五角星 / 月牙 / 叶子 / 圆点 / Q 版
- 「鲸尾」**不是**鲸鱼娘，是鲸鱼这个生物的共同视觉元素 —— 鲸鱼不是任何人的版权，鲸尾剪影也没有独创性门槛
- **优点**：完全合法、可公开发布、可开源、体积极小（每个 < 400 字节 Path）
- **缺点**：不如角色形象有辨识度

> 这是**默认方案**，已按 `design/05` 实现。

---

## 2. 方案 D：用户自己导入形象（**零风险，已实现**）

- App 只提供「从相册选择 / 从剪贴板粘贴」入口，**不分发任何素材**
- 用户自己在网上找到鲸鱼娘图片，自己存手机里，自己导入
- **优点**：完全合法（App 只是图片查看器）、可公开发布、可开源
- **缺点**：用户要自己找图；且如果用户自己公开发布导入了版权图的截图，那是用户自己的问题（App 不承担）

> 这是**推荐的公开发布方案**，已按 `design/05 §4` 实现。

## 3. 方案 B：找 ZipZipPipe 谈授权（**能开箱即用，需沟通**）

### 3.1 找谁

| 对象 | 身份 | 联系方式 |
|---|---|---|
| **ZipZipPipe** | B 站 UP 主，43,917 粉丝，签名「龙娘伟大，伟大龙娘」，鲸鱼娘女仆装作者 | B 站私信（`space.bilibili.com` 搜 ZipZipPipe） |
| **上善无形** | OC「溟月」原作者，2026-08-02 声明 CC BY-NC-SA 4.0 | 需先通过 ZipZipPipe 转达（她声明里没留公开联系方式） |
| **aigengtu.com 站方** | 非营利粉丝图库，明确写「本站不代为授权」 | 只能当信息源，不能当授权方 |

**先找 ZipZipPipe**：她是让鲸鱼娘火起来的人，也是「禁止商用」声明的发出者。上善无形已经用 CC 协议开放了二创，理论上只要**署名 + 非商用**就合规，但 ZipZipPipe 的版本叠加了更严的「禁止商用」，所以**必须两个人（或至少她）都同意**才最稳。

### 3.2 私信话术（B 站，300 字以内，可直接复制）

```
ZipZipPipe 你好！

我是「墨语」输入法的开发者。这是一个 iOS 端的 AI 输入法，纯本地、
零后端，目前只在朋友之间小范围装（走免费签名），没有上架 App Store，
也完全免费、没有任何付费或广告。

我在做一套「AI 双色主题」，想把鲸鱼娘做成一枚很小的角落形象
（22pt，只有指甲盖那么大，放在键盘右下角，不抢任何视觉）。
配色会严格用你作品的主色系，整体极简，不会有任何花哨装饰。

我知道你声明过禁止商用。我这个项目：
- 完全免费，没有收入，没有广告，没有订阅
- 不开源、不公开发布，只在朋友之间装
- 每个界面上会明确标注「形象 © ZipZipPipe，基于上善无形「溟月」」
- 如果你哪天觉得不合适，我立刻下架

想先问你一句：这种「非公开发布的免费个人项目」可以用吗？
如果不行完全理解，我改用几何符号方案就行。
另外想问一下，如果要公开发布（GitHub 开源），需要什么条件？

占用了你的时间，非常感谢！
```

### 3.3 话术要点（为什么这么写）

| 写法 | 目的 |
|---|---|
| **先说清楚「不赚钱」** | NC 条款的唯一争议点在这里，先堵住 |
| **说清楚「不公开发布」** | 大幅降低她的顾虑（不是「拿我的画去引流」） |
| **说清楚「很小」** | 很多画师介意的是「大图商用」，22pt 角落形象跟「大图」心理距离很远 |
| **主动给署名方案** | 显示你懂规矩，不是来白嫖的 |
| **主动给「立刻下架」承诺** | 降低她的决策成本 —— 她最怕的是「答应了以后撤不掉」 |
| **主动问「公开发布需要什么条件」** | 把话题从「能不能」转到「怎么才能」，成功率更高 |
| **结尾给台阶** | 「不行完全理解」让拒绝变得容易，反而更容易得到「其实可以」 |

### 3.4 如果她同意，要拿到什么

**书面的**（B 站私信截图即可，最好让她明确说出下面几个词）：
1. ✅ 授权范围：**哪个形象**（鲸鱼娘女仆装？还是「溟月」本体？）
2. ✅ 使用方式：**App 内小尺寸展示**
3. ✅ 分发范围：**仅个人非公开发布** / **可公开发布**（这两者差别很大）
4. ✅ 是否可修改（比如简化为极简线条版）
5. ✅ 署名要求：**具体怎么写**（「形象 © ZipZipPipe」还是「© ZipZipPipe / 上善无形」）
6. ✅ 是否可商用（**这条很关键，如果她说不行，就永远不要上架收费**）

**没拿到的**：
- ❌ 口头「可以吧」→ 不足以作为凭据，建议让她明确说「可以用在 XX 项目上」
- ❌ 站方（aigengtu.com）说可以 → 不作数，站方明确写了不代授权

### 3.5 如果她不同意 / 不回

**不要等**。方案 A（几何符号）+ 方案 D（用户导入）已经覆盖所有场景，先发布这两个，她回复了再加热。

如果她同意但只允许「非公开发布」：那就保持现状（侧载 + 朋友之间），**永远不要把你的项目改成开源公开仓库**，或者开源时把形象相关代码/资源全部剥离到一个不公开的分支。

## 4. 三条不要做的事

| ❌ 不要 | 为什么 |
|---|---|
| 不要用鲸鱼娘的图做 App 图标 | 图标是品牌标识，侵权风险最高，且 Apple 审核指南 4.1 明确禁止 |
| 不要在任何公开页面（GitHub README / 官网 / 应用商店截图）展示角色图 | 「展示」本身也可能构成「向公众提供」 |
| 不要写「灵感来自鲸鱼娘」然后照样用 | 标注来源不等于获得授权；《著作权法》第二十四条的「适当引用」不适用于装饰性使用 |

---

## 5. 一句话

> **自己用 → 随便用。给朋友装 → 风险很低。公开发布 → 先拿授权，拿不到就用几何符号（方案 A）+ 让用户自己导入（方案 D）。**
