## 发现但未改，以及真机待验项

- **高，跨进程个人词库覆盖。** App 和键盘各持一份全量词典，两端同时编辑时，后写的一方仍可能覆盖另一方。同实例的串行写入已修复。跨进程合并需定义计数、删除和清空的冲突规则，并验证两种签名存储。`ios/Shared/IMECore/UserLearningStore.swift:388`
- **中，API Key 共享副本失败。** 共享钥匙串的写、删接口没有向调用方报告系统状态；锁屏或签名权限变化时，仍需检查各副本一致性。现有批量删除 API 仅处理本地 service，当前界面没有调用。改变跨进程删除策略需验证共享权限和其他进程中的副本。`ios/Shared/Storage/SharedVault.swift:53`、`ios/Shared/Storage/KeychainStore.swift:213`
- **中，语音回退的来源和目标。** Darwin 控制信号以及通用剪贴板的语音标记不提供发送方认证。切到 App 录音再返回时，系统重新提供的文档也可能不同于最初发起录音的输入框。完整绑定需要跨进程会话协议，并验证不共享权限时的操作流程。`ios/Shared/Voice/VoiceBridge.swift:158`、`ios/AIKeyboardExtension/Core/KeyboardSession.swift:1087`
- **中，扩展内存和主线程。** base64 生图响应仍需先接收 JSON 再解码，图片历史仍在主线程读写。首次读钥匙串、键盘关闭时等待学习数据落盘也可能阻塞；语音心跳会重复读取共享偏好。静态检查不能确定耗时和内存峰值，改动存储时机需实测挂起、唤醒和取消。`ios/Shared/Networking/ImageClient.swift:222`、`ios/AIKeyboardExtension/AI/ImageHistory.swift:49`、`ios/AIKeyboard/App/VoiceSession.swift:347`
- **中，通知解压和损坏的词库。** 偏好通知压缩体有长度上限，解压后的数据缺少独立上限。内置词库读取器信任表偏移和记录，损坏的资源可能越界。当前随包文件已逐项核对。通知格式兼容和键盘冷启动成本需要在 Apple 平台测量。`ios/Shared/Storage/SharedSync.swift:58`、`ios/Shared/IMECore/MoyuDictionary.swift:92`
- **真机待验。** iOS 16 的签名组合、完全访问关闭和重新开启、语音授权期间关闭、连续录音、剪贴板授权、微信等宿主的选区与换框、横屏拖高和深浅色均未在这台 Windows 机器上运行。布局或视觉表现没有足够证据支持改动。
