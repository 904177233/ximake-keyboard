# 01 · 产品需求与方案（PRD）

> 项目代号：**墨语 / Moyu Keyboard**
> 一句话：一颗**会 AI 的 iOS 输入法**——打字时随手润色、扩写、翻译、生成回复、直接生图，不切 App 也能把 AI 塞进对话框。
> 状态：设计基线 v1.0（Lead 制定，所有子智能体以此为准）

---

## 1. 背景与问题

用户在微信 / iMessage / 小红书 / 邮件里聊天时，常见低效动作：

1. 想说得更得体 → 切到 ChatGPT/DeepSeek → 复制粘贴 → 再切回来（来回 4~6 次点击，打断心流）。
2. 想发一张配图 → 切到生图 App → 生成 → 保存 → 回聊天 → 从相册选。
3. 想翻译一句外语 → 切翻译 App。
4. 输入法自带的"联想/剪贴板/快捷短语"能力弱，重输入、低智能。

**机会**：输入法是唯一常驻在"输入现场"的系统级入口。把 LLM/生图能力做进键盘，用户**不离开当前聊天**就能完成改写、翻译、生图，交互链路从 6 步降为 1 步。

## 2. 目标与非目标

### 2.1 目标（MVP）
| # | 目标 | 验收标准 |
|---|---|---|
| G1 | 一个能在真机装上、能打字的中文拼音输入法 | 26 键 + 9 键，全拼/简拼/混拼候选，联想与用户词学习 |
| G2 | 键盘内一键调用 AI，结果可直接上屏 | 润色 / 扩写 / 翻译 / 回复建议 / 生图 5 个能力，流式输出，≤2 次点击发起 |
| G3 | 任何 OpenAI 兼容 / Anthropic / Gemini 接口都能接 | 用户填 baseURL + key + model 即可用，内置 9 家国内常见服务商预设 |
| G4 | iOS 原生审美，与 iMessage/微信 同框不违和 | 设计令牌统一、深色/浅色、玻璃质感、44pt 点击区 |
| G5 | 无开发者账号也能长期自用 | 免费 Apple ID 签名路径 + 7 天续签指南 + 无 App Group 的降级方案 |

### 2.2 非目标（本期不做）
- ❌ 不做 App Store 上架/TestFlight 分发（无开发者账号）
- ❌ 不做云同步账号体系（无后端；配置本地/剪贴板搬运）
- ❌ 不做语音输入（**平台限制**：键盘扩展拿不到麦克风，Apple 官方能力表无此项，开完全访问也无解，见 `docs/09` §1）
- ❌ 不做五笔/双拼全套方案（预留扩展点，v1 聚焦拼音）
- ❌ 不做越狱/侧载商店分发、不做盗版签名证书
- ❌ 不做 Android / 鸿蒙

## 3. 目标用户与场景

**主用户**：中文母语、日常重度微信/社交聊天、已经在用 ChatGPT/DeepSeek 等 API（或愿意花 5 分钟配 key）的技术敏感用户。**这就是本项目用户本人。**

**核心场景（按优先级）**
1. **S1 润色上屏**：打完一段话 → 点 ✨润色 → 流式预览 → 一键替换。
2. **S2 回复建议**：对方发来一段话 → 点 🧠回复 → 3 条候选，点一条直接上屏。
3. **S3 翻译**：中文打一半 → 🌐翻译 → 中↔英/日/韩。
4. **S4 生图**：打一句描述 → 🎨生图 → 复制图片 → 回聊天长按粘贴。
5. **S5 日常打字**：候选、联想、快捷短语（`dz`→邮箱）、剪贴板历史。

## 4. 功能清单（MoSCoW）

### 4.1 键盘（P0）
- 26 键 QWERTY（中文拼音 + 英文直通），9 键九宫格拼音（可切换）
- 候选栏：横向滚动、分页、首候选高亮、候选长按（词频/删除学习）
- 功能键：地球（切键盘）、地球长按（键盘列表）、空格、回车、退格（长按连删）
- 数字/符号页、Emoji 页（最近使用 + 分类，纯 Unicode）
- 键盘内 **AI 工具条**（签名元素）：玻璃胶囊横向滚动，`✨润色 💬扩写 🌐翻译 🧠回复 🎨生图 ⚙️设置`
- AI 面板：输入框（可带上下文）+ 语气选择（自然/简洁/礼貌/正式/热情）+ 发送
- 结果卡片：流式打字机、复制、插入（替换选区/追加）、重试、编辑后插入、关闭
- 生图结果：缩略图 + 复制图片；提示"复制后在宿主 App 长按粘贴"
- 键盘内设置 Sheet：Provider 管理/API Key/语气/短语/剪贴板开关/配置导入导出

### 4.2 AI 能力（P0）
| 能力 | 输入 | 输出约束 |
|---|---|---|
| 润色 | 当前输入框文本/选中文本 | 只输出改写后正文，不加解释、不加引号，长度与原句相近 |
| 更礼貌 / 更简短 / 更正式 / 更口语 | 同上 | 同润色，按语气调性 |
| 扩写 | 一句短话 | 2~4 句，保留原意，不编造事实 |
| 翻译 | 中文/外语 | 只输出译文；自动识别方向，可指定目标语言 |
| 回复建议 | 对方消息（用户粘贴或上下文） | 恰好 3 条候选，每条 ≤30 字，分号或换行分隔，风格各异 |
| 生图 | 中文描述 | 返回图片；提示词自动翻译/增强为英文 |
| 自定义 | 任意 | 用户自定义 Prompt 模板 |

### 4.3 主 App（P0）
- 引导（添加键盘 → 完全访问 → 配 Provider）
- 设置（Provider CRUD + 连通性测试 + 默认模型/语气/条数/生图尺寸）
- Prompt 模板库（内置 + 自定义 CRUD）
- AI 试验场（全屏试用所有能力，含生图）
- 安装与续签指南
- 诊断页（扩展/权限/网络/Keychain/词库版本）
- 隐私开关（剪贴板历史、本地学习）

### 4.4 P1/P2
- P1：多语言候选、繁简切换、滑动输入、候选长按编辑、AI 结果历史
- P1：截图 OCR / 图片理解（需视觉模型）
- P2：云同步、快捷指令、iPad 优化（语音输入不列入排期：键盘扩展无麦克风权限，见 §2.2）

## 5. 关键体验指标（自用可量化）
- 冷启动到可打字 ≤ 1.2s；按键响应 ≤ 16ms；内存常驻 ≤ 60MB（扩展）
- 从「点 AI 能力」到「首字可见」≤ 1.5s（网络正常）
- 首候选命中率 ≥ 85%（常用句子）
- AI 插入成功率 100%（文本类），无重复插入/丢字

## 6. 硬约束（决定架构，务必遵守）

| 约束 | 影响 |
|---|---|
| **无 Apple Developer Program（免费 Apple ID）** | 签名有效期 7 天；无 App Group、无 iCloud、无 Push；Bundle ID 需唯一且全小写 |
| 键盘扩展**必须开启"完全访问权限"**才能联网 | 设置引导必须显式教用户开启；无权限时给出友好降级提示 |
| 键盘扩展内存预算 ~40–60MB | 不缓存大图、不加载大 JSON、词库按需/分片加载 |
| iOS 16.0 起（覆盖 iPhone 8/X 之后多数机型） | 不用 iOS 17+ 专有 API，玻璃质感用 `.ultraThinMaterial` 降级 |
| 只能编译于 macOS（Xcode） | Windows 上产出完整可编译工程 + 资源 + 构建文档，用户在 Mac 上打开签名 |
| 零第三方依赖 | 纯 Swift/Foundation/SwiftUI/UIKit，词库用内置 TSV，网络用 URLSession |

## 7. 用户可见文案基线（中文）
- 产品名：墨语（副标题：会 AI 的输入法）
- 未配置 AI 时提示：「还没有配置 AI 服务 · 点此设置」
- 无完全访问权限：「需要在"设置 › 键盘"中开启"允许完全访问"，AI 才能联网」
- 错误文案统一中文 + 一句可执行建议（见 05 文档）

## 8. 风险与对策
| 风险 | 对策 |
|---|---|
| 免费签名 7 天过期、续签麻烦 | 文档化 3 条续签路径；App 内显示"签名剩余天数"提醒 |
| 键盘扩展被系统杀/内存超限 | 懒加载、图片只留缩略图、词库分片 |
| API 中转站格式五花八门 | Provider 预设 + 自定义 header + baseURL 归一化 + 清晰错误码 |
| 无 App Group 配置要填两遍 | 键盘内设置 + 剪贴板配置桥 + 「同步到键盘」按钮 |
| 键位/pbxproj 手写易错 | 生成器脚本 + 结构校验器 + 兜底"新建工程拖入源码"路径 |
