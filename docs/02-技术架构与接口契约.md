## 2. 构建配置约定
- 两个 target：`AIKeyboard`（宿主 App，bundle id 占位 `com.example.moyu`）、`AIKeyboardExtension`（`com.example.moyu.keyboard`）。
- 源文件归属：`ios/Shared/**` 同时加入两个 target；`ios/AIKeyboard/**` 只加 App；`ios/AIKeyboardExtension/**` 只加扩展。
- `SWIFT_VERSION = 5.0`，`IPHONEOS_DEPLOYMENT_TARGET = 16.0`，`TARGETED_DEVICE_FAMILY = 1,2`，`CODE_SIGN_STYLE = Automatic`，`DEVELOPMENT_TEAM` 留空。
- 扩展 Info.plist 必须：`NSExtensionPointIdentifier = com.apple.keyboard-service`，`NSExtensionPrincipalClass = $(PRODUCT_MODULE_NAME).KeyboardViewController`，`RequestsOpenAccess = YES`，`IsASCIICapable = YES`，`PrimaryLanguage = zh-Hans`。
- **无 App Group**（免费签名不支持）：默认 entitlements 不声明 App Groups；提供可选 `.appgroup.sample`。

## 3. 编码规范（会被 QA 静态检查）
1. 缩进 4 空格；文件编码 UTF-8 无 BOM；行尾 LF。
2. 禁止 `try!`、`as!`、`fatalError` 进入发布路径；强制解包 `!` 仅允许在 `@IBOutlet`/已知非空常量并加 `// SAFE:` 注释。
3. 扩展 target 内**绝对禁止** `UIApplication.shared`（编译不过/上架审核不过）；用 `UIInputViewController` 能力替代。
4. `Shared/IMECore` 与 `Shared/Networking` **不得 import UIKit/SwiftUI**（Service 层保持可测）。
5. 所有面向 UI 的状态机在 `@MainActor`；跨 actor 传递用 `Sendable` 值类型。
6. public API 必须有 `///` 文档注释（中文）。
7. 每个文件 ≤ 600 行；超过就拆。
8. 用户可见文案全部中文；代码注释中文；类型/变量名英文。
9. 依赖注入优先（构造函数传 `ConfigStore`/`LLMClient`），便于测试。
10. 不引入任何 SPM/CocoaPods/Carthage 依赖。

### 4.1 Models（③ ai-service 实现）
```swift
public enum ProviderKind: String, Codable, CaseIterable, Sendable {
    case openAICompatible, anthropic, gemini, custom
}

public struct AIProviderConfig: Identifiable, Codable, Equatable, Sendable {
    public var id: String              // UUID().uuidString
    public var name: String            // "DeepSeek"
    public var kind: ProviderKind
    public var baseURL: String         // https://api.deepseek.com/v1
    public var model: String           // deepseek-chat
    public var imageModel: String?     // 生图模型（可选）
    public var temperature: Double     // 0...2, 默认 0.7
    public var maxTokens: Int          // 默认 1024
    public var timeout: TimeInterval   // 默认 30
    public var extraHeaders: [String: String]  // 自定义 header（中转站）
    public var supportsVision: Bool
    public var isDefault: Bool
    public init(...)                   // 全部带默认值的成员初始化
}

public enum AIFeature: String, Codable, CaseIterable, Sendable {
    case polish, expand, translate, replySuggestion, image, custom
    public var title: String       // 润色 / 扩写 / 翻译 / 回复建议 / 生图 / 自定义
    public var systemImage: String // SF Symbol 名
}

public struct ChatMessage: Codable, Hashable, Sendable {
    public enum Role: String, Codable, Sendable { case system, user, assistant }
    public var role: Role
    public var content: String
}

public struct ChatRequest: Sendable {
    public var messages: [ChatMessage]
    public var temperature: Double?
    public var maxTokens: Int?
    public var stream: Bool
    public init(messages: [ChatMessage], temperature: Double? = nil, maxTokens: Int? = nil, stream: Bool = true)
}

public struct TokenUsage: Codable, Sendable { public var promptTokens: Int; public var completionTokens: Int; public var totalTokens: Int }
public struct ChatDelta: Sendable { public var text: String; public var isFinal: Bool }
public struct ChatResult: Sendable { public var text: String; public var usage: TokenUsage?; public var finishReason: String? }

public struct ImageRequest: Sendable {
    public var prompt: String
    public var size: String        // "1024x1024"（内部统一用 x；DashScope 侧自动转 "1024*1024"）
    public var quality: String     // "standard"/"hd"/"high"/"medium"
    public var count: Int
}
public struct GeneratedImage: Sendable {
    public var data: Data?         // 解码后的图片（≤4MB）
    public var remoteURL: URL?     // 若服务端只给 url（有效期 24h，勿长期保存）
    public var mimeType: String?   // "image/png"
}
```

#### 4.1.1 生图 Provider 预设（用户已拍板：即梦/豆包、通义万相，OpenAI 兼容兜底）

| 预设名 | 协议 | baseURL | imageModel |
|---|---|---|---|
| 即梦 · 火山方舟 | Ark / OpenAI 兼容 | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seedream-3-0-t2i-250415` |
| 通义万相 · DashScope | **异步任务** | `https://dashscope.aliyuncs.com` | `wanx2.1-t2i-turbo` |
| OpenAI 兼容 / 中转站 | OpenAI | 自定义 | `gpt-image-1` / `dall-e-3` |

- 即梦：`POST /images/generations`，`{"model","prompt","size","response_format":"url","watermark":false}` → `data[].url` → 下载。
- 通义万相：`POST /api/v1/services/aigc/text2image/image-synthesis`（`X-DashScope-Async: enable`）→ `output.task_id` → 轮询 `GET /api/v1/tasks/{id}`（1.5s→3s 退避，总超时 90s）→ `output.results[].url`。
- **生图与对话可以是不同 Provider**：`ConfigSnapshot.imageProviderID: String?`（新增，默认 nil → 回退默认对话 Provider）。
- `AIClientFactory.makeImage(config:apiKey:)` 内部用 `ImageClientRouter` 按 baseURL/model 关键字自动路由（`ark.cn-beijing.volces.com`/`seedream` → 即梦；`dashscope`/`wanx` → 万相；其余 → OpenAI 兼容）。

```swift
public protocol LLMClient: Sendable {

    func generate(_ request: ImageRequest) async throws -> [GeneratedImage]

public enum AIError: LocalizedError, Sendable {
    case notConfigured          // 未配置服务
    case missingAPIKey
    case unauthorized           // 401/403
    case rateLimited(retryAfter: TimeInterval?)
    case server(code: Int, message: String)
    case network(String)
    case timeout
    case decoding(String)
    case contentRejected(String)
    case cancelled
    case unknown(String)
    public var errorDescription: String?  // 中文一句话
    public var recoverySuggestion: String? // 中文可执行建议

```
必做：SSE 增量解析（`\r\n`、跨 chunk 半行、`[DONE]`、注释行、`data:` 前缀）、baseURL 尾斜杠归一化、`Task` 取消即断流、401/429 映射、超时（`URLSessionConfiguration.timeoutIntervalForRequest`）、指数退避重试（仅幂等 GET/生图且 ≤2 次）。

### 4.6 IMECore（④ ime-core 实现）

```swift
    public var id: String { text + "|" + pinyin }

    public var pinyin: String
    public var score: Double
    public enum Kind: String, Sendable { case word, emoji, english, punctuation, learned }
    public var kind: Kind
}

public struct DictionaryEntry: Codable, Sendable { public var pinyin: String; public var text: String; public var frequency: Int; public var flags: String }

public final class PinyinDictionary {

    public var wordCount: Int
```

## 6. 跨模块数据流

```
用户按键 → KeyboardViewModel.tap → PinyinEngine.candidates → 候选栏
上屏   → proxy.insertText / setMarkedText → UserLearningStore.recordSelection
点 AI  → AIService(feature, text=proxy.documentContextBeforeInput, tone)
       → AIClientFactory.makeLLM(config, keychain.apiKey) → AsyncThrowingStream<ChatDelta>
       → KeyboardViewModel.aiState = .streaming(追加) → 结果卡片
插入   → proxy.insertText(结果)  （替换选区：先 deleteBackward 选区长）
生图   → ImageClient → UIPasteboard.general.image = img  （提示用户长按粘贴）
配置   → App 内编辑 → ConfigSnapshot → SharedStore/PasteboardBridge → 键盘内设置读取
```

## 7. 验收闸门
1. **可编译性**（无法在 Windows 编译，用静态审查替代）：类型/签名与本契约一致，无未定义符号，无 UIKit 误用。
2. **一致性**：UI 颜色/字号/间距必须来自 `Theme`（QA 检查硬编码）。
3. **中文文案**：无英文占位 UI 文案（除模型名/URL）。
4. **文档**：每个模块有 README 或模块级注释说明职责、依赖、已知限制。
5. **降级路径**：无完全访问 / 无网络 / 未配 Key / 服务端报错，四种情况都有可读提示。
