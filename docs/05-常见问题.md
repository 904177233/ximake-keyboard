## A. 安全与隐私

### Q1. 墨语会不会偷我的 API Key？会不会上传我的聊天内容？

**不会。** 三条硬事实：

| 项目 | 实际情况 |
|---|---|
| 有没有服务器 | **没有**。本项目没有任何后端代码，没有云函数，没有数据库 |
| Key 存哪 | 只存在你 iPhone 的 **Keychain（系统钥匙串）**，由 iOS 加密保护，其他 App 读不到 |
| 有没有埋点/统计 | **没有**。零第三方 SDK、零分析工具、零崩溃上报、零广告 |
| 代码可信吗 | 全部源码在你本地/GitHub 私有仓库，可以自己看或让懂代码的朋友看。没有二进制黑盒 |

**唯一会「发出去」的东西**：你点 AI 按钮后，**你输入框里的文字**会被发到**你自己配置的那家 AI 服务商**（DeepSeek/OpenAI/通义…），因为要让他们生成结果。这和你用 ChatGPT 网页版输入文字是同一件事。**墨语自己不接收任何数据。**

> 如果你连服务商也不信任，唯一办法是不联网用（见 Q3）。

### Q2. 我的聊天记录、剪贴板会不会被上传？

**不会。** 数据流只有一条：

```text
你按 AI 按钮 → 把「输入框里的文字」+「你的 Prompt 模板」→ 发给你配的服务商 → 返回结果
```

- **不会**读你的聊天窗口历史（iOS 也不允许键盘读）。
- **不会**读剪贴板，除非你自己点「粘贴上下文」。
- **剪贴板历史功能默认关闭**。开启后只在**本机**存最多 50 条，可在设置里一键清空。

### Q3. 断网 / 飞行模式还能用吗？

**能打字，不能用 AI。** 两种模式区别：

| 功能 | 断网时 | 说明 |
|---|---|---|
| 拼音输入、候选词、联想 | ✅ 正常 | 词库打包在 App 里，完全离线（约 5～10 万词条） |
| 用户词学习、常用短语 | ✅ 正常 | 全部本地存储 |
| Emoji、符号、数字键盘 | ✅ 正常 | 纯 Unicode 字符，不联网 |
| ✨润色 / 💬扩写 / 🌐翻译 / 🧠回复 / 🎨生图 | ❌ 不能用 | 会提示「网络连接失败，请检查网络」 |
| 配置同步（同步到键盘） | ✅ 正常 | 走本机剪贴板，不需要网络 |

> **开了完全访问但没联网**：AI 按钮会转圈几秒然后报错。这是正常的，不是 bug。

### Q4. 为什么键盘一定要「允许完全访问」？会不会很危险？

**「完全访问」只做一件事：允许键盘扩展联网。** 不开的话键盘是一个完全离线的沙盒，**AI 功能全部不可用**（因为没有网络权限）。

「允许完全访问」在技术上确实**同时**允许键盘读取剪贴板、向宿主 App 发网络请求。所以苹果把它做成用户显式授权。对本项目的风险判断：

| 风险点 | 墨语的情况 |
|---|---|
| 偷读你复制的密码 | 代码里只有你点「粘贴上下文」时才读剪贴板，没有后台轮询 |
| 键盘记录你所有输入并上传 | 没有上传通道（没有服务器、没有埋点） |
| 读其他 App 数据 | iOS 沙盒不允许，键盘只能看到当前输入框 |
| 上传到第三方 | 只有你配置的 AI 服务商，且只在点 AI 按钮时 |

**结论**：本项目的完全访问是"必要且透明"的。但请你自己判断——如果你不信任任何第三方键盘（包括这个），就不要开完全访问，那样只能当普通拼音输入法用。

### Q5. 我输入的每一个字都会上传吗？

**不会。** 只有这三种情况会发网络请求：

1. 你点了 **AI 按钮**（✨💬🌐🧠🎨）→ 发送**输入框当前文字**
2. 你点了 **测试连接** → 只发一个极小的探测请求
3. 你点了 **生图** → 发送你写的图片描述

**你正常打字、选候选词、按空格上屏，全程不发任何网络请求。** 拼音计算和候选排序全在本地完成。

### Q6. 换手机 / 重装 App，Key 和词库会丢吗？

**会丢，需要重新配。** 因为免费签名**没有 iCloud 同步**、也没有 App Group，数据只在**当前这台设备的 App 沙盒 + Keychain** 里。

| 数据 | 换手机/重装后 | 怎么恢复 |
|---|---|---|
| API Key | ❌ 丢 | 在 App 里重新填一次（1 分钟） |
| 服务商配置（baseURL/模型） | ❌ 丢 | 重新配，或事先截图 |
| 用户词学习 | ❌ 丢 | 重新学习（用得越多越准，1～2 天就回来了） |
| 常用短语 | ❌ 丢 | 建议事先在备忘录备份一份文本 |
| Prompt 自定义模板 | ❌ 丢 | 同上，备份文本 |
| 剪贴板历史 | ❌ 丢 | 无所谓（隐私敏感，不恢复更好） |

**迁移技巧**：换手机前，打开旧手机 App → 「同步到键盘」→ 去任意输入框长按粘贴，把那段 `MOYU_CONFIG_V1...` 文本**发到新手机**（微信/邮件都行）→ 新手机 App 里如果有「从剪贴板导入」就用；没有的话只能手动重配。

## B. 安装与续签

### Q7. 7 天到期会怎样？数据会丢吗？

**App 会打不开，键盘会失效，但数据不会丢。**

到期后你会看到：
- 桌面「墨语」图标还在，但点开**闪退**，或提示「无法验证 App」
- 键盘列表里「墨语」点进去**一片空白**，或直接消失
- 正在打字时突然跳回系统键盘

**解决**：按 `docs/04` 第 9 章重签一次（5～10 分钟），**所有数据原样保留**（Keychain 和 UserDefaults 都不会被清除，因为 App 从来没被真正卸载）。

> ⚠️ **千万别做的两件事**：①不要把 App 从桌面长按删除（那是真卸载，数据全没）；②不要在「设置 › 通用 › iPhone 储存空间」里「删除 App」。**只要不卸载，重签就是无缝恢复。**

### Q8. 为什么一定要每 7 天搞一次？能不能一次装好永久用？

**不能。** 这是苹果对**免费 Apple ID** 的硬限制：用免费账号签名的 App，有效期最长 **7 天**（这是苹果服务器签发的证书有效期，不是代码能绕过的）。

| 解决方案 | 效果 | 成本 |
|---|---|---|
| 每 7 天重签（本文方案） | 一直能用，但要手动 | ¥0 |
| 买 Apple 开发者账号 | **1 年**不用管 | **$99/年**（约 ¥700） |
| 越狱 | 理论上可永久 | 风险极高，**强烈不推荐**（安全性、稳定性、失去保修） |
| 上架 App Store | 永久 | 需要 $99 账号 + 通过审核 + 本项目定位是自用 |

### Q9. 我用 Windows，真的完全不需要 Mac 吗？

**真的不需要。** 流程是：

```text
GitHub 的免费 macOS 服务器编译（云端，你不用有 Mac）
        ↓ 产出未签名 IPA
下载到你的 Windows
        ↓
iloader 用你的 Apple ID 在本地签名
        ↓
装进 iPhone
```

唯一"像 Mac"的地方是 `docs/04` 第 7 章的**路线 B**（备选），那条路需要 Mac，**但你不用走**。

> **代价**：GitHub Actions 有免费额度（Private 仓库每月 2000 分钟 macOS 编译，一次约 3～6 分钟 → 每月够跑约 300 次，完全够用）。

### Q10. 我完全不懂代码，能自己搞定吗？

**能，但第一次要耐心。** 首次约需 **60～90 分钟**，主要时间花在：注册 GitHub、装 iTunes、等云端编译。

你必须会做的只有 3 件事（都在 `docs/04` 有截图级步骤）：

2. 在 GitHub 网页点下载（**点鼠标**）

> **如果卡住了**：把报错信息拿去 `docs/04` 第 10 章的**报错对照表（16 条）**里搜，90% 的问题都能找到答案。

### Q11. 我装好了，但「设置 › 通用 › 键盘」里找不到「墨语」！

这是**第一大坑**，99% 是同一个原因：**IPA 里没有键盘扩展（PlugIns 目录丢了）**。

排查顺序（照做）：

| 步骤 | 操作 | 判断 |
|---|---|---|
| 1 | 把 IPA 改名为 `.zip`，解压 | — |
| 2 | 看 `Payload\AIKeyboard.app\PlugIns\` 目录在不在 | **不在** → IPA 打包漏了扩展，装一百次也没用，报告给开发者修 workflow |
| 3 | 若在，看里面有没有 `AIKeyboardExtension.appex` | 没有 → 同上 |
| 4 | 若都有，去 设置 › 通用 › 键盘 › 键盘 › 添加新键盘 | 找不到「墨语」→ 重启 iPhone 再看 |
| 5 | 能找到但勾不上 | 先在桌面打开一次「墨语」App，再回来勾 |
| 6 | 都能勾但打字切不过去 | 确保你勾了**至少 2 个键盘**（只有 1 个键盘时地球键行为不同） |

> 详细图文见 `docs/04` 第 4.4 节和第 5.3 节。

### Q12. 键盘能打字了，但一点 AI 就转圈 / 提示"需要完全访问"

三个原因，按顺序查：

| 顺序 | 检查 | 路径 |
|---|---|---|
| 1 | **「允许完全访问」开了吗** | 设置 › 通用 › 键盘 › 键盘 › 点「墨语」那一行（不是勾选框）→ 开「允许完全访问」→ 点「允许」 |
| 2 | **Key 配了吗** | 打开桌面「墨语」App → 服务商 → 填 Key → 测试连接成功 |
| 3 | **配置同步到键盘了吗** | App 里点「同步到键盘」→ 键盘 ⚙️ 设置 → 「从剪贴板导入」 |

> 如果三步都对还转圈：换网络试（有些公司 Wi-Fi 墙了 API 域名），或用手机流量试。

## C. 功能能力

### Q13. 支持哪些 AI 服务商？我只有国内的 Key 行不行？

**行。** 内置 9 家预设，覆盖国内外：

| 类型 | 服务商 | 说明 |
|---|---|---|
| 国内直连 | **DeepSeek**、**通义千问（阿里）**、**Kimi（月之暗面）**、**智谱 GLM**、**火山方舟（豆包）**、**硅基流动** | 中文好、便宜、国内网络直连不需要梯子 |
| 国外 | **OpenAI**、**Anthropic（Claude）**、**Google Gemini** | 需要能访问的网络环境 |
| 聚合 | **OpenRouter** | 一个 Key 用多家模型 |
| 自定义 | **任意 OpenAI 兼容接口** | 自建中转站、公司内网网关都行：自己填 baseURL + 模型名 + Key |

**填法**：选预设 → 一般只需填 API Key（baseURL 和模型名已预填）→ 点「测试连接」→ 成功即可。
**中转站**：选「自定义 / OpenAI 兼容」→ baseURL 一般填到 `/v1` 结尾（例如 `https://你的域名/v1`）→ 模型名按中转站文档填 → Key。

### Q14. 生图为什么不能直接插进聊天框？

**因为 iOS 的硬限制：键盘扩展只能插入「纯文字」，不能往宿主 App 里插图片。**

键盘能做的只有两件事：`insertText("文字")` 和 `deleteBackward()`。这是苹果 `UITextDocumentProxy` 协议的能力边界，**不是本项目偷懒**：

| 想做的事 | 键盘能不能 | 原因 |
|---|---|---|
| 插入文字 | ✅ 能 | `insertText` |
| 删除字符 | ✅ 能 | `deleteBackward` |
| 移动光标 | ⚠️ 部分能 | 只能按固定步数移动 |
| **插入图片** | ❌ **不能** | 协议里没有这个方法，任何第三方输入法都做不到 |
| 直接发消息 | ❌ 不能 | 键盘不能点宿主 App 的发送按钮 |

**所以本项目的生图流程是**：

```text
① 键盘里写图片描述（或按 🎨 用当前文字）→ 生成
② 生成完成 → 自动复制到剪贴板 + 显示缩略图
③ 你手动：切到聊天框 → 长按 → 「粘贴」
```

> UI 上会明确提示「图片已复制，在聊天框长按粘贴」，不是让你猜。

### Q15. 回复建议是怎么工作的？它能读到我朋友发的话吗？

**读不到聊天窗口历史**（iOS 不允许键盘访问其他 App 的界面内容）。它能拿到的只有**当前输入框里的文字**。

三种用法：

| 用法 | 怎么做 | 效果 |
|---|---|---|
| **直接生成** | 输入框是空的，直接点 🧠回复 | 生成 3 条通用回复（"好的"/"收到，我看看"/"稍等我确认下"） |
| **粘贴上下文**（推荐） | 先复制对方的消息 → 键盘 AI 面板点「粘贴上下文」→ 再点 🧠回复 | 3 条针对性的回复建议 |
| **先打草稿再改写** | 自己先打几个字 → 🧠回复 | 基于你的草稿生成更完整的回复 |

**生成的 3 条建议**每条 ≤30 字，点一下直接插入，或者点「编辑」改完再插入。

### Q16. 翻译支持哪些语言？能自动识别方向吗？

**能自动识别。** 逻辑是：

| 你输入的内容 | 自动判断 | 翻译成 |
|---|---|---|
| 中文 | 检测到中文字符 | **英文** |
| 英文/其他拉丁字母 | 检测到非中文 | **中文** |
| 中英混合 | 按中文字符占比 >30% 判为中文 | 英文 |

支持的目标语言：**中、英、日、韩、法、德、西、俄**（在 AI 面板的语言选择里可手动指定，覆盖自动判断）。

> 用的是大模型翻译，不是传统机翻，语气和上下文会好很多。专有名词（人名、品牌、代码）一般能保留。

### Q17. 润色/扩写/回复这些功能，具体能干什么？

| 按钮 | 干什么 | 举例（输入 → 输出） |
|---|---|---|
| **✨ 润色** | 改通顺、去语病，不改意思 | "我今天有点事可能来不了" → "我今天临时有点事，恐怕没办法过去了，非常抱歉" |
| **💬 扩写** | 2～4 句，把一句话展开 | "这个方案不错" → "这个方案整体思路很清晰，尤其在成本控制上考虑得比较周到。我觉得可以先小范围试点，验证后再推广。" |
| **🌐 翻译** | 中英互译（自动判方向） | 见 Q16 |
| **🧠 回复** | 生成 3 条回复建议 | 见 Q15 |
| **🎨 生图** | 文字描述 → 图片（复制到剪贴板） | "一只戴眼镜的橘猫在写代码" → 生成图片 |
| **⚙️ 设置** | 打开键盘内设置面板 | 服务商/语气/词库/完全访问状态 |

**语气选择**（影响润色/扩写/回复）：自然 / 简洁 / 礼貌 / 正式 / 热情。默认「自然」。

### Q18. 我的词库能加词吗？学了不该学的词怎么删？

**能加能删。**

| 操作 | 路径 |
|---|---|
| **加词** | 打开「墨语」App → **词库** → 右上角 **+** → 输入拼音和词 → 保存。之后打字时该词会优先出现 |
| **加常用短语**（快捷输入） | App → **短语** → **+** → 填「触发码」+「内容」，例如 `dz` → `北京市朝阳区xxx`。打字时输入 `dz` 会出现在候选栏 |
| **置顶短语** | 短语列表左滑 → 置顶，永远排第一 |
| **删除学错的词** | App → **词库** → **学习记录** → 找到那个词左滑删除，或点「清空学习记录」 |
| **关闭学习** | App → 设置 → 关闭「用户词学习」。之后只用手动词库 |
| **恢复出厂词库** | App → 设置 → 词库 → 「重置为内置词库」（**会清掉你加的词，慎用**） |

### Q19. 剪贴板历史怎么用？安全吗？

**默认关闭**（隐私考虑）。开启路径：App → 设置 → 「剪贴板历史」→ 打开。

| 项 | 说明 |
|---|---|
| 存多少条 | 最多 50 条，自动淘汰最旧的 |
| 存哪里 | 只在本机 App 沙盒，**不上传** |
| 能干什么 | 键盘 AI 面板「粘贴上下文」时可以从历史里挑；键盘设置里能快速插入历史片段 |
| 敏感内容 | 建议**不要**在复制密码/验证码时开启。或者用「一键清空」 |
| 清空 | App → 设置 → 剪贴板历史 → 「清空全部」；或键盘 ⚙️ → 剪贴板 → 清空 |

### Q20. 有没有 AdGuard 那种"输入法云同步"？我在另一台 iPhone 上也能用同样的配置吗？

**没有云同步**（这是本项目的定位：纯本地）。要在第二台 iPhone 上用：

1. 那台也必须**用同一个 Apple ID 走一遍安装流程**（`docs/04`），或者用你自己的签名装
2. 配置需要重新填，或在旧设备上「同步到键盘」后把那段 JSON 文本传过去粘贴

> **为什么不支持 iCloud 同步？** 需要 Apple 开发者账号（$99/年）+ iCloud entitlement。免费签名开不了。

## D. 输入体验

### Q21. 支持双拼 / 五笔 / 笔画 / 手写吗？

| 输入方式 | v1 支持 | 说明 |
|---|---|---|
| **全拼** | ✅ | 标准拼音，如 `nihao` → 你好 |
| **简拼** | ✅ | 只打声母，如 `nh` → 你好 |
| **混拼** | ✅ | 声母+部分韵母，如 `nih` → 你好 |
| **双拼** | ❌ | v1 不做（涉及多套键位方案，工作量大）。代码里预留了扩展点 |
| **五笔** | ❌ | v1 不做 |
| **笔画输入** | ❌ | v1 不做 |
| **手写** | ❌ | 需要系统手写识别框架，键盘扩展内限制多，v1 不做 |
| **语音输入** | ⚠️ | **还没做，但大概率能做（iOS 26+）**。三条独立证据：①五家上架输入法的 App Store 描述都有键盘内语音手势（百度「长按空格即说即发」、讯飞「长按技能坞」、搜狗、微信、Gboard）；②`hkgood/OSGKeyboard`（minOS 26.0）的**扩展** Info.plist 声明了 `NSMicrophoneUsageDescription`；③Apple open access 文档的开发者责任段写 "don't store received keystroke or **voice** data..."。现行文档那句 "No access to microphone and speaker" 位于 **`RequestsOpenAccess=false`** 的限制清单里。**前提**：开完全访问（墨语已是 true）+ 补两个 Usage 字符串 + 30 分钟真机验证。详见 [`docs/08`](08-AI输入法能力调研报告.md) §5.1 与 [`docs/09`](09-iOS键盘扩展能力边界技术约束清单.md) §1 |
| **滑动输入** | ❌ | 需要轨迹识别算法，v1 不做 |

> 如果你**必须**用双拼/五笔，那这个项目不适合你——建议用系统键盘或商业输入法。**说清楚比做成半成品好。**

### Q22. 26 键和 9 键怎么切换？两种都能用吗？

**两种都实现了，能随时切。** 切换方式：

| 方式 | 路径 |
|---|---|
| 键盘内快速切换 | 键盘 ⚙️ 设置 → 「键盘布局」→ 26 键 / 9 键 |
| App 内设置 | 「墨语」App → 键盘设置 → 布局 → 26 键 / 9 键 |

**区别**：

| | 26 键（QWERTY） | 9 键（九宫格） |
|---|---|---|
| 适合 | 习惯全键盘、打英文多 | 单手打字、中文更顺 |
| 英文输入 | ✅ 原生支持 | 需要切字母页 |
| 数字 | 顶部一行或切数字页 | 副键显示 |
| 单键大小 | 约 33×42pt | 更大，约 110×42pt |

> 布局选择会记住，下次打开还是上次那个。默认 **26 键**。

### Q23. 字体能改吗？键盘高度能调吗？

**都不能，是刻意不做的。**

| 项 | 情况 | 原因 |
|---|---|---|
| 字体 | 固定系统字体（SF Pro / 苹方），字号按设计令牌 | 键盘空间极小（258pt 高度），自选字体会让候选词/按键错位 |
| 文字大小 | 跟随系统「文字大小」设置到一定程度，但不完全跟随 | 同上 |
| 键盘高度 | **固定 258pt**（竖屏）/ 200pt（横屏） | 键盘扩展有严格内存限制（约 40～60MB），动态高度会增加内存压力 |
| 深色模式 | ✅ **自动跟随系统** | 深色/浅色两套配色都做了 |
| 主题色 | ❌ 不可改（固定 iOS 蓝 `#0A84FF`） | 保持原生审美一致性 |

> 如果你觉得字太小：设置 › 显示与亮度 › 文字大小 调大，键盘会跟随一部分。

### Q24. iPad 能用吗？

**理论上能（`TARGETED_DEVICE_FAMILY` 包含 iPad），但 v1 没有针对 iPad 优化。**

| 项 | 情况 |
|---|---|
| 能装吗 | ✅ 能（如果你的签名流程支持，iPad 也在 10 台设备限制里） |
| 能用吗 | ⚠️ 能打字，但布局按 iPhone 尺寸做的，在 10 寸屏上会**按键很大、间距奇怪** |
| 优化了吗 | ❌ 没有。iPad 键盘有专用布局（浮动、分体），本项目没做 |
| 建议 | iPad 上建议用系统键盘；本项目定位是 iPhone 单手/双手打字 |

### Q26. 能上架 App Store 吗？能给朋友装吗？

**都不能。**

| 想做的事 | 能不能 | 原因 |
|---|---|---|
| 上架 App Store | ❌ | 需要 $99/年账号 + 通过审核。而且输入法类审核极严（需说明数据用途），本项目不做 |
| 上 TestFlight | ❌ | TestFlight 也需要 $99 账号 |
| **给朋友装** | ❌ **不能** | 免费签名的 App 绑定**你的** Apple ID 和证书，朋友手机上装不了。他必须自己走一遍 `docs/04` 用自己的 ID 签 |
| 发给朋友安装包（IPA） | ⚠️ 能发，但他要自己签 | 而且 IPA 里没有你的 Key（Key 在 Keychain，不在 IPA 里），所以**发 IPA 不会泄露 Key** |
| 公开分发 | ❌ | 同上，每个人都要自己签名 |

> **定位**：这是一个**个人自用**项目，不是产品。接受这一点能省掉很多幻想。

### Q27. 换 Apple ID 会怎样？

**App 会失效，需要重签。**

| 情况 | 结果 |
|---|---|
| 只是 iPhone 登录了另一个 Apple ID（App Store 账号） | 已装的 App **还能用**（7 天内），但**续签会失败**——新 ID 没有旧 ID 的证书 |
| 换 ID 后重新用新 ID 签名 | ✅ 可以，但会变成「新的 App」，**旧数据可能不保留**（因为签名身份变了，iOS 可能视为不同 App） |
| 想彻底换 ID | 建议：先在旧 App 里把配置截图备份 → 删除旧 App → 用新 ID 走一遍 `docs/04` → 重新配 |

> ⚠️ **免费账号最多 3 个 App ID**。如果你之前用同一个 ID 签过别的 App（比如 AltStore 的 App），可能额度已满，会报 `maximum App ID limit`。解决：去 <https://developer.apple.com/account> 删掉不用的 App ID。

### Q28. 我在公司电脑 / 网吧电脑上做这些，安全吗？

**不安全，别这么做。**

| 风险 | 说明 |
|---|---|
| Apple ID 密码泄露 | iloader 需要输你的 Apple ID 密码（含 2FA），在别人电脑上输 = 把账号交给别人 |
| 证书被盗 | 签名后的证书存在电脑上，别人可以拿去签别的 App（用你的名义） |
| IPA 被篡改 | 中间人替换 IPA 可能植入恶意代码 |

**要求**：只在**你自己拥有/完全控制的电脑**上做签名。做之前电脑要干净（无木马/无键盘记录器）。
