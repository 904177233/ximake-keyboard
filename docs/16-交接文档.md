## 七、故障速查

### 7.1 `usbmux list_devices()` 返回 0，但手机明明插着

**根因**：`CM_PROB_PHANTOM` 幽灵设备实例让 Apple Mobile Device Service 一直重试。

```powershell
# 先确认是不是真没插：PresentOnly 里应能看到 Apple iPhone
Get-PnpDevice -PresentOnly | Where-Object { $_.InstanceId -like '*VID_05AC*' }

# 清理幽灵（必须动态枚举！端口号会从 &2& 变 &4&，硬编码实例号只能清一批）
Get-PnpDevice | Where-Object { $_.InstanceId -like '*VID_05AC&PID_12A8*' } |
  ForEach-Object { pnputil /remove-device $_.InstanceId }
Restart-Service "Apple Mobile Device Service"
pnputil /scan-devices
```

上一步需**提权**（`Start-Process pwsh -Verb RunAs`），且提权窗口的 stdout 不回传 → 写日志再读。

### 7.2 iloader 重启后要求重新登录 / 登录失败

- **`Input.insertText` 是追加不是替换**：重复重试会把 Apple ID 拼成 `z***3@icloud.comz904177233@icloud.comz904177233@icloud.com` → Apple 返回 `-20970`。
  - 解法：填表前先 focus → Ctrl+A → Backspace → 再 `Input.insertText`

   - 我们已用 v2.0「键盘内完整配置服务商」绕过；但**宿主 App 里配的东西键盘读不到**，反过来也一样。
   - 付费开发者账号（$99）开启 App Groups 后，把 `SharedStore.appGroupIdentifier = "group.com.moyu.keyboard"` 配好即可零改代码打通。
2. **7 天签名过期**：免费证书 7 天到期，需重新签名安装。
3. **生图无法直接插入输入框**：`UITextDocumentProxy.insertText` 只能写文本。已改为「保存到相册」。
4. **语音输入需要 iOS 26+ 且宿主 App 先授权**：键盘扩展内不允许弹权限框（会收起键盘并切输入法），必须先在「墨语 App › 设置 › 语音权限」里允许麦克风与语音识别。此结论需在 iOS 27 真机再确认一次。
5. **iOS 27 的 bundle 布局限制**：bundle 根下不能有名为 `Resources/` 的目录（`installd` 会报 `IXErrorDomain Code=13 Missing bundle ID`）。已改为 `dict/`，**不要改回去**。
