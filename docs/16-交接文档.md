> 更新：2026-11-05。分支 `redesign-v3`。旧版（v2.5.1）的交接文档在 `docs/archive/16-交接文档.md`，装机和故障速查还可以参考。
> 界面原型：`design/prototype-v3.html`，浏览器打开就能打字。

## 这次重做了什么

键盘和 App 的界面全部重写，AI 请求层和提示词保留（那部分是踩坑踩出来的，比如网关不守 SSE 规范的宽松解析）。

| 模块 | 怎么做的 | 文件 |
|---|---|---|
| 词库 | 从 3.3 万条扩到 9.6 万条，单字补全多音字，改成内存映射的二进制文件 | `tools/dict/build_binary.py`、`ios/Shared/dict/moyu.dict` |
| 转换 | 26 键和九宫格共用一套动态规划，支持逐词选词 | `ios/Shared/IMECore/PinyinEngine.swift` |
| 键区 | 一个视图自己画所有键、自己处理所有触摸 | `ios/AIKeyboardExtension/Keys/` |
| 状态 | 全部集中在一个类里 | `ios/AIKeyboardExtension/Core/KeyboardSession.swift` |
| AI | 润色、翻译、回复、扩写、画图共用一个面板，对话单独一页 | `ios/AIKeyboardExtension/AI/`、`Panels/` |
| App | 三页：开始、AI、键盘 | `ios/AIKeyboard/` |
| 配置打通 | 运行时试钥匙串访问组，能写进去就两边共用 | `ios/Shared/Storage/SharedVault.swift` |

## 改掉的毛病

- 九宫格是假的：按 ABC 只打出 a。现在是真九宫格，左栏选拼音。
- 符号页没有入口，打不出逗号句号。现在主键盘有逗号句号，上滑问号叹号；字母键上滑打数字和符号。
- 打不了英文：所有字母都进拼音。现在有中/英键，Shift 能打大写。
- 长句只能整句选，错一个字要删光。现在选一个词，剩下的拼音接着转换。
- 回车在打字时把拼音和换行一起发出去。现在先确认原文，不会把半截拼音发出去。
- 润色结果接在原文后面，变成两段。现在是替换原文。
- 面板内容不更新：第一次读到的文字会一直用下去。现在每次打开都重读。
- 回复功能在输入框为空时报错，可那正是要回复的时候。现在先让你读复制的那句话。
- 翻译永远翻成英文。现在按原文判断方向，也能手选语言。
- 候选栏的箭头是收起候选，看不到更多候选。现在箭头是展开，工具入口另外给。
- 按键之间有死区，快打丢字。现在最近的键接住每次触摸，第二根手指落下时第一个键立刻出字。

## 故意去掉的

都是用得少或者说不清用处的，要的话可以加回来：

- 在线词库包：内置词库已经够大，这条下载和回滚的链路维护成本高。
- AI 试验场：App 首页放了一个输入框，直接用键盘试。
- 提示词模板管理：键盘里本来就没有入口。
- 诊断页：出错信息现在直接显示在面板里，带服务器原话。
- 对话里说「画一张」触发画图：现在 AI 面板有「画图」页签。

## 还没验证的（重要）

这台电脑没有 Mac，**这些代码只过了静态检查，还没被真编译器编译过**。上一轮的教训是静态检查全绿也可能编译失败好几次。

1. **编译**：要推到 GitHub 跑云编译，`.github/workflows/build.yml` 已经加上这个分支。
2. **内核测试**：云编译第一步会跑 `tools/imecheck/main.swift`，用真词库测逐词选词、九宫格、简拼、多音字、学习，还会打印没参与调词频的句子的准确率。
3. **配置打通**：`SharedVault` 依赖签名工具有没有把钥匙串访问组写进包里。打不通会自动退回各存各的，App 首页会显示「没打通」，这时用「发给键盘」搬配置。
4. **真机手感**：键区的触摸逻辑只能在手机上感受。
5. **语音输入**：和旧版一样，没在真机上验证过。

## 词库怎么改

想让某个词排得更靠前：在 `tools/dict/extra_words.tsv` 加一行 `词<TAB>词频`，然后：

```
python tools/dict/build_binary.py --eval
```

`--eval` 会打印常见句子的整句转换结果。整句转换目前没有上下文模型，只靠词频和规则，同音字选错是预期内的，点候选能改，选过之后会记住。要进一步提高，需要更好的词频数据或者二元语言模型，这两样都得联网取数据。
