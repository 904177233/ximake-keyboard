# 交付验收清单

按任务选择适用项。没有实际执行的测试必须标为未验证，不得写成通过。

## 内容与视觉

- [ ] 页面有真实任务、完整主要动作和真实感内容，不是风格展示壳。
- [ ] 首屏阅读顺序明确，唯一主要动作突出，次要动作不争夺注意。
- [ ] 网格、间距、字级、色板、圆角和图标有系统性，非随机参数。
- [ ] 去除材质/动效后，信息层级仍成立。
- [ ] 空、加载、错误、成功、禁用状态按场景完整。

## 动效与交互

- [ ] 每处动效有触发、目的、前后状态、时长、缓动和结束/中断行为。
- [ ] 主要连续动画优先 transform/opacity，不触发布局抖动。
- [ ] 抽屉、菜单、对话框同时设计进入与退出，不只写 enter。
- [ ] 快速重复点击、切换路由、反向滚动时不会叠加失控。
- [ ] 滚动不劫持、不阻塞阅读；错列不拖慢首要内容。
- [ ] 动画结束状态不依赖 hover，触屏仍可完成操作。
- [ ] `prefers-reduced-motion: reduce` 移除视差、大位移、持续运动，保留清晰状态。

## 响应式与可访问性

- [ ] 在 1440、720、390、320px 检查标题、数据、按钮与控件。
- [ ] 无内容裁切、意外横向滚动、遮挡或固定高度造成的溢出。
- [ ] 中文换行、长单词、动态数据、200% 字体缩放有合理处理。
- [ ] 语义 HTML、标签、可访问名称、跳转/标题结构按场景齐全。
- [ ] 键盘可完成主要任务；focus-visible 明显，弹层焦点进入、循环、返回正确。
- [ ] 状态不只靠颜色，文字与关键控件对比足够；透明背景下单独验证。
- [ ] 触控目标足够大，交互不依赖精确悬停。

## 实现验证

- [ ] 构建、类型检查、lint 和已有测试按项目实际配置执行。
- [ ] 浏览器控制台无新增错误；主要操作真实走通。
- [ ] 检查长列表、动画和低性能场景；没有未验证的 FPS 数字承诺。
- [ ] 报告实际执行项和限制，而非“完全符合所有标准”。
