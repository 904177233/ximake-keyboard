# 设计风格速查

根据任务选风格。每条是设计方向的摘要，不是完整复刻原网站；原文链接统一为 `https://spicytater.cn/terms/<slug>`。

| 风格 / slug | 适用任务与关键视觉决策 |
|---|---|
| 装饰艺术 `art-deco` | 典礼、文化、精品；几何秩序、金属色点缀、对称与仪式感，装饰不遮内容 |
| 便当格 `bento-grid` | 多功能概览；有主次的不等尺寸网格，一个核心入口，不把每段内容机械卡片化 |
| 黏土拟态 `claymorphism` | 健康、生活、个人效率；柔和体积与圆润模块，操作边界和文字对比明确 |
| Frutiger Aero `frutiger-aero` | 环保、健康、大众科技；自然意象、水与光、高亮材质，入口保持清楚 |
| Material Design `material-design` | 工作台与服务；表面层级、连续动效、明确浮动动作和状态反馈 |
| 现代简约 `minimalism` | 内容密集但重点明确；结构、留白、少量字级，装饰退后 |
| 趣味插画 `playful-illustration` | 学习、活动、团队；插画参与解释流程，不只是角落装饰 |
| SaaS 官网 `saas-marketing-site` | 订阅软件获客；价值主张、真实工作流、信任证据、试用转化有节奏衔接 |
| 瑞士排版 `swiss-style` | 公共信息、展览、产品；严格网格、客观排版、清晰时间/地点/规格 |
| Y2K `y2k` | 音乐、相机、个人主页；早期数字设备、透明层和金属质感，内容仍可操作 |
| B2B 官网 `b2b-corporate-site` | 企业复杂决策；按角色组织方案、可信证据、案例和专家咨询入口 |
| 包豪斯 `bauhaus` | 展览、产品、建筑；基础几何、红黄蓝、功能与形式统一 |
| 深色界面 `dark-ui` | 长时工作、媒体、密集状态；多级深色表面，不能简单反色或依赖霓虹 |
| DTC 电商 `dtc-e-commerce` | 品牌直销；产品材料与价值、价格、交付、评价、复购连成一体 |
| 杂志编辑风 `editorial` | 专题、新闻、文化；不等宽网格、主视觉、文字与留白建立阅读节奏 |
| 扁平化 `flat-design` | 城市服务、门户、活动；色块与层级直接表达内容，减少质感噪音 |
| Fluent Design `fluent-design` | 桌面与协作；导航、间距、轻材质和控件行为适应大小屏 |
| 未来主义 `futurism` | 实时数据与探索；清晰系统关系优先于无意义 HUD、扫描线和粒子 |
| 玻璃拟态 `glassmorphism` | 环境工作台、天气、媒体；少量半透明前景 + 背景模糊 + 细边缘；文字与焦点独立可读 |
| 手绘风 `hand-drawn-ui` | 工作坊、创作者；不规则线条与手写标注，真实内容关系不能松散 |
| 高对比界面 `high-contrast-ui` | 政务、公共信息；语义色对、明确边界，状态绝不只靠颜色 |
| 极繁主义 `maximalism` | 文化、艺术、时装；经编排的颜色、图案和节奏，丰盛而非随机堆叠 |
| 孟菲斯 `memphis` | 活动、创意；强形状、饱和色与 playful 构图，信息秩序仍清楚 |
| 单色设计 `monochrome` | 作品、商品、文章；单色系内以明度、比例和空间分层 |
| 新粗野主义 `neo-brutalism` | 公告、申请、活动；硬边框、高对比、不对称，直接行动路径 |
| 新拟态 `neumorphism` | 计时、音频等单任务；凸起/嵌入表达触感，标签与状态不淡化 |
| Notion 风 `notion-style` | 团队知识工作区；页面树、块、数据库与多视图组织可持续编辑内容 |
| 有机设计 `organic-design` | 护肤、旅宿、家居；自然曲线、触感与产地故事，行动入口保持清楚 |
| 像素风 `pixel-art` | 复古游戏、独立作品；像素网格、状态和动作参与叙事，正文可读 |
| 拟物化 `skeuomorphism` | 陌生数字对象；纸、旋钮、书架等熟悉心智模型，反馈不依赖材质 |
| 终端极客风 `terminal-aesthetic` | 开发、运维；等宽字体、命令与输出、准确状态，不伪造技术装饰 |
| 日式侘寂 `wabi-sabi` | 慢生活、空间、器物；木纸石陶、柔和光、不完美与留白 |
| Apple HIG `apple-hig` | 移动、平板、桌面；系统导航、熟悉控件、内容优先、即时反馈 |

## 组合原则

- 风格不是组件模板；先保留信息结构，再增加材质。
- 辅助风格只借一种维度，例如“瑞士网格 + 新粗野主义边框”，不要两个完整主题相互争夺。
- 材质移除测试：去掉透明、阴影、纹理、动效后，标题、状态和主要动作是否依然明确？否则先修信息结构。
