# 高级 UI 与动效

把“做得高级”翻译为可执行、可验收的设计决策。内容任务与操作路径优先；材质和动效服务层级与反馈。

## 工作流程

1. **判断输出**：用户要提示词时输出完整提示词；要实现时直接完成代码和验证。不把提示词当作实现交付。
2. **收集已知条件**：产品任务、目标用户、平台/技术栈、主要内容、关键动作、已有品牌/设计系统。缺少非关键条件时选择合理方案并注明，不用连续追问。
3. **定义设计方向**：用 1 个主风格 + 可选 1 个辅助手法；说明气质、布局、字体、色彩、材质、图形语言。避免无目的地混搭。
4. **组织真实界面**：导航、标题、正文、数据/媒体、主要动作、状态反馈。勿用 lorem ipsum；避免所有内容套同一种浮动卡片。
5. **编排动效**：每处动效回答“为什么动”。采用下面的运动规格，优先 `transform` 和 `opacity`。
6. **响应式与无障碍**：检查 1440、720、390、320px；键盘焦点、语义、对比度、触控、减少动态效果必须纳入。
7. **验收**：逐项对照 `references/quality-checklist.md`。实现任务须真实运行项目或测试，不能只声称完成。

## 将模糊词翻译为规格

| 用户说 | 应具体化为 |
|---|---|
| 高级感 | 清晰的网格和留白、有限色板、明确的字级、克制的材质、少量有因果的动效 |
| 动画流畅 | 触发对象、前后状态、时长、缓动、合成属性、离场与中断行为 |
| 丝滑滚动 | 原生滚动优先；分区进度或轻微视差，不劫持滚轮、不阻挡阅读 |
| 有空间感 | 尺度、遮挡、前后景和层次变化；不靠均匀阴影或满屏玻璃卡片 |
| 有生命力 | 1 个标志性动作 + 克制微交互；不让所有元素持续漂浮、呼吸或闪烁 |

## 动效规格（按需取值，不机械全加）

- **微反馈** 120–180ms：hover、按压、开关、focus；位移 1–3px，缩放不低于 0.97。
- **普通进入/退出** 180–280ms：透明度配合 8–16px 位移；退场通常更短。
- **抽屉/对话框** 220–320ms：使用 `cubic-bezier(0.16, 1, 0.3, 1)`；遮罩淡出与面板分离编排。
- **主要区块进入** 400–650ms：子项错列 40–80ms，总错列限制在约 240ms；首次进入后不要每次滚动反复播放。
- **页面过渡** 200–400ms：共享元素或轻微交叉淡化，保留导航上下文；不为了转场阻塞操作。
- **列表变化**：使用布局/FLIP 过渡表达新增、移除、重排；保持焦点与屏幕阅读器通知。
- **标志性场景**：最多 1 个主视觉；用滚动进度、遮罩揭示、形变或分层视差之一。手机降级，绝不造成横向滚动。

缓动：进入用 ease-out，退出用 ease-in，连续状态变化用 ease-in-out。弹性只用于轻松、可逆的小部件，避免高回弹和长时间摆动。无限动画只用于真实的加载、录制或播放状态。

## 动效提示词模板

```text
为【对象】制作【目的】动效。
触发：【点击 / 进入视口 / 数据更新 / 滚动进度 / 状态切换】。
状态：从【初始状态】到【结束状态】；视觉关系【为何这样移动】。
参数：【transform / opacity】，时长【ms】，缓动【曲线】，错列【ms】。
交互：hover、pressed、focus-visible 各自如何反馈；连续操作时如何中断和接续。
降级：窄屏与低性能设备如何简化；prefers-reduced-motion 下移除位移/视差，保留即时状态或短淡入。
验收：布局不抖动，滚动不阻塞，焦点不丢失，信息不依赖动画才能读取。
```

## 完整 UI 提示词模板

```text
请为【用户与场景】设计并实现【页面/组件】，使用【技术栈】。
核心任务：用户需要【完成什么】；主要动作是【动作】。
真实内容：【标题、正文、数据、导航、表单、状态】。
设计方向：【主风格】，呈现【3 个以内的气质词】。
布局：【网格、阅读顺序、留白、视觉锚点】；不套无意义卡片。
视觉系统：【字体层级、有限色板及语义色、间距、圆角、边框、材质/图像】。
交互与动效：列出 2–4 个关键交互，分别给出触发、前后状态、时长、缓动、错列、退出/中断规则。
响应式：1440、720、390、320px 下【重排方式】；无裁切、无横向滚动。
可访问性：语义结构、键盘操作、可见焦点、状态文字、足够对比；支持 prefers-reduced-motion。
避免：装饰抢走内容、全屏粒子、无目的漂浮、渐变滥用、纯颜色传达状态、虚假数据。
验收：主要任务可完成，状态完整，控制台无错误，并检查上述尺寸与 reduced-motion。
```

## 风格选择

需要词条时读取 `references/style-atlas.md`，选择符合任务而非最炫的风格。网站提供的 33 种风格均可从该速查表定位；本 Skill 是方法提炼，不是逐字转载。

常用映射：
- 清晰、专业、内容优先：Minimalism、Swiss Style、Editorial、Monochrome。
- 产品工作台：Material Design、Fluent Design、Apple HIG、Notion Style、Dark UI。
- 轻盈空间：Glassmorphism（少量玻璃层 + 有意义的环境背景）。
- 柔和亲和：Claymorphism、Playful Illustration、Organic Design。
- 强烈表达：Neo-Brutalism、Bauhaus、Maximalism、Memphis、Y2K。
- 商业转化：SaaS Marketing Site、B2B Corporate Site、DTC E-commerce。

## 禁止项

- 不把“高级”写成大量渐变、光斑、阴影、玻璃、粒子和回弹的叠加。
- 不为了动效牺牲输入、滚动、可读性、焦点、性能或加载稳定性。
- 不将动画参数当成所有设备的硬编码保证；根据任务和现有设计系统调整。
- 不声称已经测试未实际测试的浏览器、尺寸、性能或可访问性。
