# 组件库 · SwiftUI 组件 API 契约

> 版本 v1.0 ｜ 适用：`ios/AIKeyboardExtension/`（keyboard-ui）与 `ios/AIKeyboard/`（host-app-ui）
> 数据源：`design/tokens.json`（键名唯一真相）
> 目标平台：iOS 16.0+，Swift 5，SwiftUI，零第三方依赖
>
> **本文是契约，不是建议。** 组件名、参数名、枚举 case 名、tokens 键名三者必须逐字一致；QA 会做交叉校验。
> 如果某个组件在实现时不得不偏离，请在代码里加 `// CONTRACT-ADD: <原因>` 注释，并在交付说明里列出，不要静默改名。

## 0. 快速导航与命名归一

工程里同时出现了「task 描述里的名字」和「用户口径的名字」，**以本表右列为准**，不要两种都实现：

| 别名/旧称 | 本契约的正式名 | 说明 |
|---|---|---|
| `Chip` / `ToolChip` | **`PillChip`** | 唯一胶囊组件，靠 `style` 区分用途 |
| `PillButton` | **`PrimaryButton`** / `SecondaryButton` | 按钮只有这两种，胶囊形状由 `shape: .capsule` 控制 |
| `ListRow` | **`SettingsRow`** | 通用行组件，`SettingsRow` 是正式名 |
| `Segmented` | **`SegmentedTabs`** | |
| `CapCard` | **`SurfaceCard`**（`CapCard` 仅作 `typealias`） | 卡片的通用名是 `SurfaceCard`；`typealias CapCard = SurfaceCard` 保留兼容 |
| `Theme` 颜色 | `Theme.<name>`（见 §1.1） | 直接照 docs/02 §4.5 的 15 个 static let |

组件分三层，实现顺序建议也是这个顺序：

```
L0 令牌层   Theme.swift（ai-service 提供，UI 只读）
L1 原子     GlassSurface / PillChip / PrimaryButton / SecondaryButton / IconGlyph / ProgressDots
L2 键盘域   KeyCap / CandidateBar / AIBar / StreamingText / AIResultCard / ToneSelector / SheetHeader
L3 主App域  SurfaceCard / SettingsRow / SegmentedTabs / EmptyState / ErrorBanner / SectionHeader / ProviderRow / StepCard
```

## 1. L0 令牌层约定（与 Theme.swift 的对应关系）

### 1.1 颜色：tokens 键 → Swift 符号

Theme.swift 必须提供下列 15 个 `public static let ...: Color`，**名字照抄 docs/02 §4.5**。括号里是它对应的 `tokens.json` 键；深色适配由 Theme 内部完成（`UIColor(dynamicProvider:)`），UI 侧**永远不要**自己判断 colorScheme 取色。

| Swift 符号 | tokens 键（light / dark 同名键） | 用途 |
|---|---|---|
| `Theme.keyboardBackground` | `bg.keyboard` | 键盘整块底色 |
| `Theme.keyBackground` | `bg.key` | 字母键键帽 |
| `Theme.keyBackgroundPressed` | `bg.key.pressed` | 键帽按压态 |
| `Theme.keyFunctionBackground` | `bg.key.function` | 回车/退格/Shift/数字切换等功能键 |
| `Theme.surface` | `bg.surface` | 卡片、Sheet 内容底 |
| `Theme.surfaceElevated` | `bg.surfaceElevated` | 分组页面背景、输入框底 |
| `Theme.textPrimary` | `text.primary` | 主文字 |
| `Theme.textSecondary` | `text.secondary` | 副标题、说明、占位符 |
| `Theme.accent` | `accent` | 主色（iOS 系统蓝 #0A84FF） |
| `Theme.accentSoft` | `accent.soft` | 选中底、高亮底（8–20% 透明度） |
| `Theme.separator` | `separator` | 分隔线（半透明） |
| `Theme.success` | `success` | 成功/已连接 |
| `Theme.warning` | `warning` | 警告/未开启权限 |
| `Theme.danger` | `danger` | 错误/删除 |
| `Theme.candidateBar` | `candidate.bar` | 候选栏底 |
| `Theme.fontCandidate` | `typography.candidate` | 17pt regular |
| `Theme.fontKey` | `typography.key` | 22pt regular |
| `Theme.fontBody` | `typography.body` | 15pt regular |
| `Theme.fontCaption` | `typography.caption` | 12pt regular |
| `Theme.fontTitle` | `typography.title` | 20pt semibold |
| `Theme.Spacing.xs/sm/md/lg/xl` | `spacing.xs..xl` | 2/4/8/12/16 |
| `Theme.Radius.key/card/capsule/sheet` | `radius.*` | 8/16/999/24 |
| `Theme.Motion.fast/normal/spring` | `motion.fast/normal/springDuration+springDamping` | 0.15 / 0.25 / spring(0.35, 0.82) |
| `Theme.Sizing.keyboardHeightPortrait` 等 | `sizing.*` | 见 §1.2 |

**主题扩展组**（`tokens.json` 有、docs/02 未强制）：UI 组件需要时用 `Theme.extended(.keyFunctionPressed)` 之类的轻封装读取，或者由 ai-service 直接补 `public static let keyFunctionPressed: Color` 等。**约定**：所有扩展颜色必须走同一个内部函数 `Theme.color(_ key: String)`，禁止在 View 里写 `Color(hex: "…")` 字面量（QA 会报硬编码）。

### 1.2 尺寸常量（禁止魔法数字）

| Swift 符号 | 值 | 说明 |
|---|---|---|
| `Theme.Sizing.keyboardHeightPortrait` | 258 | 竖屏键盘总高（含候选栏+AI 工具条+键区） |
| `Theme.Sizing.keyboardHeightLandscape` | 200 | 横屏总高 |
| `Theme.Sizing.candidateBarHeight` | 44 | 候选栏 |
| `Theme.Sizing.aiBarHeight` | 40 | AI 工具条 |
| `Theme.Sizing.keyHeight` | 42 | 键帽高（设计名义值，实际由行高分配，见布局规范） |
| `Theme.Sizing.aiPanelExtraHeight` | 168 | AI 面板展开增量 |
| `Theme.Sizing.resultExtraHeight` | 180 | 结果卡片展开增量 |
| `Theme.Sizing.letterRowHeight` | 39 | 字母行行高（扩展键） |
| `Theme.Sizing.keyGap` | 6 | 键间距（横向列距 = 竖向行距） |
| `Theme.Sizing.keyHorizontalPadding` | 3 | 屏幕左右边距 |
| `Theme.Sizing.minTapTarget` | 44 | 最小点击区（无例外） |

### 1.3 字号策略（重要）

**键盘扩展内所有字号固定，不随 Dynamic Type 放大**（否则 258pt 高度会溢出、候选栏抖动）。
- 键盘域组件：一律用 `Theme.fontCandidate` / `fontKey` / `fontCaption` 等固定 `Font.system(size:weight:)`，**不要**用 `.body` `.headline` `.title` 这类 Dynamic Type 字体。
- 主 App 域组件：**鼓励**用 Dynamic Type（`.font(.body)` 等），但字号基准值必须等于 tokens 的 size（用 `.font(.system(size: 15))` 再包 `.dynamicTypeSize(...DynamicTypeSize.accessibility2)` 限幅）。
- 判断依据：组件在 `KeyboardRootView` 树上 → 固定字号；在 `AIKeyboardApp` 树上 → 可缩放但限幅。

### 1.4 材质（Liquid Glass 的 iOS 16 降级）

`GlassSurface` 是唯一允许出现 `.ultraThinMaterial` 的地方，内部做版本分支：

```swift
public struct GlassSurface<Content: View>: View {
    public enum Level { case bar, card, sheet }   // 对应 tokens.material.bar/card/sheet
    public var level: Level
    public var cornerRadius: CGFloat
    public var showHighlight: Bool                 // 顶部 45% 高光（Liquid Glass 意象）
    @ViewBuilder public var content: () -> Content

    public init(level: Level = .bar,
                cornerRadius: CGFloat = Theme.Radius.card,
                showHighlight: Bool = true,
                @ViewBuilder content: @escaping () -> Content)
}
```

| level | material（iOS 16+ 均可用） | 描边 | 说明 |
|---|---|---|---|
| `.bar` | `.ultraThinMaterial` | 0.5pt `Theme.separator` | 候选栏 / AI 工具条 / 结果卡 |
| `.card` | `.thinMaterial` | 0.5pt `Theme.separator` | 主 App 卡片 |
| `.sheet` | `.regularMaterial` | 无 | Sheet 背景 |

降级规则（**必须实现**，写在 `GlassSurface` 内部一个 `@ViewBuilder private var backing`）：
1. `if #available(iOS 17.0, *)` → 直接 `.background(.ultraThinMaterial)`；iOS 16 同样有 `Material`，所以**材质 API 本身不需要降级**。
2. 真正需要降级的是「`.ultraThinMaterial` 在扩展内 CPU 开销」：当 `UIAccessibility.isReduceTransparencyEnabled == true` 时，换成 `Theme.surface.opacity(0.94)`（tokens `material.*.ios16Fallback`）。
3. 永远不要用 `.background(.ultraThinMaterial, in: .rect(cornerRadius:))`（`rect` 是 iOS 17 API），用 `.background(.ultraThinMaterial)` + `.clipShape(RoundedRectangle(cornerRadius:))`。
4. 高光层：`LinearGradient(colors: [.white.opacity(0.25), .clear], startPoint: .top, endPoint: .center)`，高度 = 组件 45%，`allowsHitTesting(false)`。

## 2. L1 原子组件

### 2.1 `PillChip`

AI 工具条、语气选择、Provider 预设、能力选择都用它。**全项目唯一胶囊组件。**

```swift
public struct PillChip: View {
    public enum Style {
        case tool        // AI 工具条：玻璃底 + 图标 + 文字，高 30
        case tone        // 语气选择：选中强调色底，高 30
        case tag         // 只读标签（型号/状态），高 22，字号 caption
        case provider    // Provider 预设：文字为主，高 32
    }
    public enum Size { case regular, compact }

    public let title: String
    public var systemImage: String?          // SF Symbol；工具条用 emoji 时传 nil
    public var emoji: String?                // 与 systemImage 二选一，emoji 优先
    public var style: Style
    public var size: Size
    public var isSelected: Bool
    public var isEnabled: Bool
    public var action: () -> Void

    public init(_ title: String,
                systemImage: String? = nil,
                emoji: String? = nil,
                style: Style = .tool,
                size: Size = .regular,
                isSelected: Bool = false,
                isEnabled: Bool = true,
                action: @escaping () -> Void)
}
```

| 属性 | 视觉 |
|---|---|
| `style == .tool` | 高 30，圆角 `Theme.Radius.capsule`，底 `chip.bg`（浅色 `#FFFFFFCC`），1pt 内描边 `chip.border`，图标 13pt + 文字 13pt medium `chip.text`，横向内边距 12，图标与文字间距 5 |
| `style == .tone` | 高 30，未选中：底 `chip.bg` 40% + 文字 `text.primary`；选中：底 `Theme.accent` + 文字 `text.onAccent`（白） |
| `style == .tag` | 高 22，圆角 `Theme.Radius.small`，底 `accentSoft`，文字 11pt medium `accent`，内边距 6 |
| `style == .provider` | 高 32，圆角 `capsule`，未选中描边 1pt `separator`，选中 `accentSoft` 底 + `accent` 文字 |
| 按压态 | `scaleEffect(0.96)` + 亮度 -6%，`Theme.Motion.fast`；`isSelected` 时无缩放（避免抖动） |
| 禁用态 | `opacity(0.4)`，不响应点击 |
| 触感 | `UISelectionFeedbackGenerator`（工具条）/ `UIImpactFeedbackGenerator(.light)`（语气） |

**不要**给 chip 加阴影（tokens 有 `shadow.chip` 但只允许 AI 工具条整条用，不允许单个 chip 用）。

### 2.2 `PrimaryButton` / `SecondaryButton`

```swift
public struct PrimaryButton: View {

    public var tone: Tone
    public var size: Size
    public var isEnabled: Bool

    public var fullWidth: Bool                 // true → maxWidth: .infinity
    public var action: () -> Void
}

public struct SecondaryButton: View {
    // 同 PrimaryButton 的 init 形状，视觉不同；tone 仅 .neutral / .destructive
}
```

| 变体 | 背景 | 文字 | 圆角 | 高度 |
|---|---|---|---|---|
| `PrimaryButton(.accent, .large)` | `Theme.accent` | `text.onAccent` 白 17pt semibold | `capsule` | 50 |
| `PrimaryButton(.accent, .medium)` | `Theme.accent` | 同上 16pt semibold | `capsule` | 44 |
| `PrimaryButton(.destructive)` | `Theme.danger` | 白 | `capsule` | 44 |
| `SecondaryButton(.neutral, .medium)` | `Theme.surfaceElevated` | `Theme.accent` 16pt semibold | `capsule` | 44 |
| `SecondaryButton(.neutral, .small)` | `chip.bg` | `text.primary` 15pt medium | `capsule` | 36 |
| 按压 | `scaleEffect(0.97)` + `opacity(0.85)`，0.15s | | | |

规则：**一个屏幕最多一个 `.accent .large`**；键盘内的「插入」「复制」用 `.small`。

### 2.3 `IconGlyph`

SF Symbol 与 emoji 的统一入口，解决「SF Symbols 不可用时降级」（视觉稿/demo/低版本系统）。

```swift
public struct IconGlyph: View {
    public let symbol: String       // SF Symbol 名，如 "sparkles"
    public var fallback: String     // 不可用时显示的文字/emoji，如 "✨"
    public var size: CGFloat        // 默认 17
    public var weight: Font.Weight  // 默认 .regular
    public var tint: Color?
}
```

- 实现：`Image(systemName: symbol)` 的可用性用 `UIImage(systemName:) != nil` 判断；nil 则渲染 `Text(fallback)`。
- AI 能力图标映射（**全局唯一，UI 两侧共用**）：

| 能力 | `AIFeature` case | SF Symbol | fallback |
|---|---|---|---|
| 润色 | `polish` | `sparkles` | ✨ |
| 扩写 | `expand` | `text.append` | 💬 |
| 翻译 | `translate` | `globe` | 🌐 |
| 回复建议 | `replySuggestion` | `bubble.left.and.bubble.right` | 🧠 |
| 生图 | `image` | `photo.on.rectangle.angled` | 🎨 |
| 自定义 | `custom` | `slider.horizontal.3` | ⚙️ |

> 键盘内 AI 工具条为控制包体与渲染成本，**优先用 emoji + 文字**（不会因 SF Symbol 缺失变空）；主 App 内优先 SF Symbols。

## 3. L2 键盘域组件

### 3.1 `KeyCap`（最核心，必须逐像素对齐布局规范）

```swift
public struct KeyCap: View {
    public let label: KeyLabel
    public var style: KeyStyle = .letter
    public var isPressed: Bool = false
    public var isHighlighted: Bool = false      // Shift 激活 / 大写态
    public var width: CGFloat? = nil            // nil → 由父容器均分；空格/回车传显式宽度
    public var height: CGFloat = Theme.Sizing.letterRowHeight
    public var action: () -> Void = {}

    public enum KeyLabel: Equatable {
        case character(String)      // "a" "中" "1"
        case symbol(String)         // "⌫" "⏎" "⇧" "🌐" "123" "空格"
        case icon(String, fallback: String)  // SF Symbol + fallback
    }

    public enum KeyStyle {
        case letter        // 白键 / 深色模式 #636366
        case function      // 灰键 / 深色 #48484A
        case accent        // 回车键（accent 底白字）或 Shift 激活
        case space         // 空格，无文字或极淡「空格」
        case ai            // AI 工具条触发键（可选，见布局规范 §3.4）
    }
}
```

| 状态 | 视觉（以 `.letter` 为例） |
|---|---|
| 默认 | 底 `Theme.keyBackground`，圆角 `Theme.Radius.key`(8)，阴影 `shadow.key`（y1 blur0 opacity0.18），文字 `Theme.textPrimary` 22pt regular，**无描边** |
| 按压 | 底 `Theme.keyBackgroundPressed`，阴影消失，`scaleEffect(0.96)`，0.08s |
| 高亮（Shift） | `.function` 底 + `Theme.accent` 字，图标变 `shift.fill` |
| `.function` | 底 `Theme.keyFunctionBackground`，图标/文字 `Theme.textPrimary` 17pt medium |
| `.accent` | 底 `Theme.accent`，字 `text.onAccent`，17pt semibold |
| 键盘内玻璃感 | `GlassSurface(.card)` **不用于单键**（性能）；用 `tokens.material.highlight` 的顶部 45% 白色渐变覆盖层实现「玻璃弧光」，`allowsHitTesting(false)` |

实现要点（避免被 QA 打回）：
1. 键帽视觉高度固定 `height`，**但点击区必须 ≥ 44×44**：用 `.contentShape(Rectangle())` + `.frame(minHeight: 44)` 外层包裹，视觉与实际点击区分离。
2. 按压态用 `ButtonStyle` 实现（`KeyCapStyle: ButtonStyle`），**不要**用 `onTapGesture`（缺少高亮、无法支持长按）。
3. 长按（退格连删）用 `.onLongPressGesture(minimumDuration: 0.35, pressing:)` + `Timer.publish(every: 0.08)`；连续删除期间 `isPressed` 保持 true。
4. 触感：字母键 `.light`，功能键 `.medium`，回车/删除 `.rigid`（`UIImpactFeedbackGenerator`，注意扩展内可用，首次调用会预热 10ms，在 `viewDidLoad` 预热一次）。
5. `.disabled` 时 `opacity(0.35)`。

### 3.2 `CandidateBar`（44pt，不得抖动）

```swift
public struct CandidateBar: View {
    public struct Item: Identifiable, Equatable {
        public let id: String          // IMECandidate.id
        public let text: String
        public let pinyin: String?
        public var kind: Kind          // .word .emoji .english .punctuation .learned
        public var kind: KMKind
    }
    public enum KMKind { case word, emoji, english, punctuation, learned }

    public var items: [Item]
    public var highlightedIndex: Int          // 默认 0（首候选）
    public var showsIndex: Bool               // 候选序号，默认 false（设置可开）
    public var pageIndex: Int                 // 当前页，0 起
    public var pageCount: Int                 // 总页数；<=1 不显示分页点
    public var composingText: String          // 正在拼的拼音串，视觉稿里显示在左侧灰色小字（可选）
    public var onSelect: (Item) -> Void
    public var onLongPress: ((Item) -> Void)?
    public var onToggleIndex: (() -> Void)?   // 长按候选栏空白处切换序号显示
}
```

| 规格项 | 值 |
|---|---|
| 高度 | **44pt 固定**（`Theme.Sizing.candidateBarHeight`），上下留白自动分配，永不随内容变化 |
| 背景 | `Theme.candidateBar`；iOS 17+ 可 `.ultraThinMaterial`，底部 0.5pt `candidate.separator` |
| 候选字号 | 17pt regular `Theme.fontCandidate`，颜色 `text.primary` |
| **首候选** | 17pt **semibold**，颜色 `accent`；若 `highlightedIndex != 0` 则第 0 项回落 regular |
| 序号 | 当 `showsIndex`：在文字左侧 12pt `text.tertiary`，与文字间距 2；**序号不计入点击区宽度**（点击命中整项） |
| 项最小宽度 | 48pt（单字候选 `48`，多字自然宽度），项间距 20pt |
| 内边距 | 左 16 / 右 16 |
| 高亮底 | 选中项圆角 `Theme.Radius.small`(6)，底 `candidate.selected`，仅覆盖文字 ±6pt 横向内边距（不是整条） |
| 分页点 | 位于右侧固定 8pt 宽区域，点 6×6，间距 5，当前页 `accent`，其余 `text.tertiary`；**总宽 = pageCount*6+(pageCount-1)*5**，>5 页时折叠为 `·` 双点（…） |
| 滚动 | 横向 `ScrollView(.horizontal, showsIndicators: false)`，`.scrollTargetBehavior` **禁止**（iOS 17 API），用 `ScrollViewReader` + `scrollTo(highlightedIndex, anchor: .center)` |
| 长按候选 | 0.45s 后弹 `Menu`：删除该词 / 加入自造词 / 上屏并记住（`.contextMenu` 即可，iOS 16 可用） |
| 空态 | `composingText` 为空且无候选时，显示 `Text("墨语 · 会 AI 的输入法")` 12pt `text.tertiary`，左对齐 16pt——**不要留白条**，避免高度塌陷感 |
| 动画 | 候选变化只做 `.opacity` 0.15s 淡入，**禁止**让整条高度变化 |

### 3.3 `AIBar`（签名元素，40pt）

```swift
public struct AIBar: View {
    public var items: [AIBarItem] = AIBarItem.defaults
    public var isEnabled: Bool = true
    public var disabledReason: AIBarDisabledReason? = nil
    public var onSelect: (AIFeature) -> Void
    public var onOpenSettings: () -> Void

    public struct AIBarItem: Identifiable {
        public let id: String
        public let feature: AIFeature
        public let title: String     // 润色/扩写/翻译/回复/生图
        public let emoji: String     // ✨💬🌐🧠🎨
    }

    public enum AIBarDisabledReason {
        case noFullAccess      // 「需开启完全访问」
        case notConfigured     // 「点此设置 AI 服务」
        case offline           // 「网络未连接」
    }
}
```

| 规格项 | 值 |
|---|---|
| 高度 | **40pt 固定**（`Theme.Sizing.aiBarHeight`） |
| 背景 | 玻璃条：`chip.bg` 12% + `.ultraThinMaterial`；上边 0.5pt `separator`；下方接候选栏时无分隔线 |
| chip 规格 | 见 `PillChip(.tool)`：高 30，圆角 capsule，内边距 12，chip 间距 8，条内左右内边距 8 |
| 边缘渐变遮罩 | 左右各 **24pt** 的 `LinearGradient(colors:[bg, bg.opacity(0)], startPoint:.leading)` 覆盖层，`allowsHitTesting(false)`，制造「可继续滑动」暗示；遮罩颜色 = 该条实际背景色 |
| 滚动 | 横向 ScrollView，`.scrollIndicators(.hidden)`（iOS 16 可用），首项与末项可滚出屏幕边缘（不要 padding 限制） |
| 点击 | `onSelect(feature)` → ViewModel 进入 `.aiPanel`（同时键盘加高 `aiPanelExtraHeight`） |
| 禁用态 | `isEnabled == false` 时 chips 降为 `opacity(0.55)` 且不滚动，条内显示居中提示文案（12pt `text.secondary`）：`.noFullAccess` → 「开启完全访问后可用 AI」；`.notConfigured` → 「还没有配置 AI 服务 · 点此设置」；`.offline` → 「网络未连接」；提示文案右侧带 `chevron.right` 图标 11pt |
| 设置入口 | 最后一个 chip 固定为 `⚙️ 设置`，`onOpenSettings()`；禁用态下整条可点跳设置 |

**动效（签名交互，必须与布局规范 §5 一致）**：
- 点击 chip → `withAnimation(Theme.Motion.spring)`：键盘高度 `258 → 258+168 = 426`，同时 `aiPanel` 从底部插入（`.move(edge: .bottom)` + 淡入），AI 工具条保持在面板顶部同一位置（**不要**让它跟着移动，它是锚点）。
- 关闭 → `spring(response: 0.28, dampingFraction: 0.9)` 收回 258。
- Reduce Motion 开启时：高度直接切换（duration 0），面板淡入 0.15s。

  - 阶段文案：`queued`→「排队中」/ `drawing`→「正在绘制」/ `enhancing`→「正在优化提示词」/ `downloading`→「正在下载」

  - **禁止**纯 `ProgressView()` 无限旋转、禁止全屏遮罩
  - 超过 20s 仍未返回：文案改为「仍在绘制，可继续等待」（`text.secondary`），取消按钮保持可用
  - 失败（内容拒绝/超时）：文案「生成失败 · 换个描述试试」+「重试」；`contentRejected` 时提示「描述可能被服务端拒绝」
- 图片结果：缩略图 `RoundedRectangle(radius 12)` 4:3，最大 160×120，右侧竖排「复制图片」「在 App 查看」；下方一行 11pt 提示「复制后回到聊天窗口长按输入框粘贴」。

## 5. 状态与动效约定（所有组件通用）

| 场景 | 规范 |
|---|---|
| 按压反馈 | `scaleEffect` 0.96–0.97，`Theme.Motion.fast`(0.15)；键盘键 0.08 |
| 展开/收起 | 键盘加高/收起用 `Theme.Motion.spring`（0.35/0.82）/ 收起 spring(0.28/0.9) |
| 列表进出 | `.transition(.opacity.combined(with: .move(edge: .bottom)))`，0.25 |
| 加载 | 骨架屏优先于转圈；短于 300ms 的加载不显示任何 loading（避免闪烁） |
| 错误 | `ErrorBanner` 淡入 0.2 + 轻微 `.offset(y: -4→0)` |
| Reduce Motion | 全局环境 `@Environment(\.accessibilityReduceMotion)`：为 true 时所有 `withAnimation` 改为无动画，位移改为淡入；键盘高度直接变化 |
| 触感 | 见各组件；统一封装 `Haptics.light/medium/rigid/selection/success/warning` |
| 声音 | 无 |

## 6. 无障碍

1. 所有可点元素 ≥ 44×44（`KeyCap` 视觉可以 39 高，但点击区 44）。
2. `KeyCap` `.accessibilityLabel`：字母 →「字母 a」/ 功能键 →「退格」「回车」「切换键盘」「空格」；`accessibilityAddTraits(.isKeyboardKey)`。
3. `CandidateBar` 每项 label = 候选文本 +（首项时）「首个候选」。
4. `PillChip` label = 标题；选中态 `.isSelected`。
5. `StreamingText`：流式时 `accessibilityLabel("正在生成")`，完成后可朗读全文；`accessibilityLiveRegion(.polite)`（SwiftUI 用 `AccessibilityNotification.Announcement`）。
6. 深色模式：全部走 Theme 动态色，禁止 `Color.black`/`Color.white` 字面量。
7. 对比度：正文 ≥ 4.5:1；`text.secondary` 在浅色 `#3C3C4399` 叠白底约 3.6:1，只用于 12pt 以上辅助文字，**不要**用于正文。
