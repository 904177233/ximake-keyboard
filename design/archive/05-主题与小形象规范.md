## 0. 三条不可协商的约束

1. **零第三方素材**。仓库里不允许出现任何鲸鱼娘 / Claude娘 等社区二创的图片、路径、配色采样。默认形象只能是**几何符号**。
2. **自定义形象由用户自己导入**（相册 / 剪贴板），App 只做存储与渲染，不分发任何素材。这是「合法 + 可公开发布」的唯一路径（见 docs/11 §2.5 方案 D）。
3. **所有颜色必须来自 `Theme`**，不得在视图里写裸色值。主题色通过 `AppTheme` 运行时覆盖 `Theme.accent` 系列的选中态语义，**不修改 Theme 的静态常量**（保持编译期常量语义与一致性检查脚本可用）。

## 1. 六套主题（配色唯一真相源）

每套 = `accent`（主色，只出现 4 处）+ `tint`（候选栏/AI 条浅底）+ `tint2`（功能键底）+ `deep`（主色深版，用于浅底上的文字）+ `sub`（候选词副文字）+ `canvas`（键盘整体背景）。

| id | 名称 | 品牌系 | accent | tint | tint2 | deep | sub | canvas |
|---|---|---|---|---|---|---|---|---|
| `ink` | 墨黑 | ChatGPT | `#101010` | `#F7F7F5` | `#EBEBEA` | `#101010` | `#3A3A3E` | `#D7D7DC` |
| `coral` | 珊瑚 | Claude | `#D97757` | `#FDF3EE` | `#F5E2D9` | `#8A4B33` | `#6B4A3E` | `#DFD6D1` |
| `indigo` | 靛蓝 | DeepSeek | `#4D6BFE` | `#EEF1FF` | `#E0E5FC` | `#2B3B9E` | `#3A4570` | `#D3D8EC` |
| `violet` | 星紫 | Gemini | `#7A5AF8` | `#F2EFFF` | `#E7E1FD` | `#4530A8` | `#4A3F72` | `#D6D0EA` |
| `sky` | 天青 | Kimi | `#2AA5E8` | `#EBF7FE` | `#DCF0FC` | `#12628C` | `#2A5068` | `#CFDFE8` |
| `pine` | 松绿 | 豆包 / 千问 | `#10A37F` | `#EDF8F4` | `#DCF1E9` | `#0A6449` | `#2A4F44` | `#CFE0DA` |

**深色模式**：`accent` 保持同色（亮色主题在深色下不易读，统一提亮 8%），`canvas` 用 `#1C1C1E` 系，`tint` 用 accent 的 18% 透明度叠在 `#1C1C1E` 上。实现上用 `UIColor { trait in }` 动态色，规则见 §1.2。

### 1.1 主色只允许出现在这 4 处（硬约束）

| 位置 | 用法 |
|---|---|
| 候选栏首选字背景 | `accent` 底 + `textOnAccent` 字 |
| AI 工具条选中胶囊 | `accent` 底 + 白字 |
| 对话旋钮 | `accent` 圆底 + 白图标 |
| 回车键 | `accent` 底 + 白字 |

**其余一切**：键帽 `#FFFFFF`、功能键 `tint2`、键盘底 `canvas`、候选栏与 AI 条 `tint`。**不许有渐变、不许有第二主色、不许有描边装饰。**

### 1.2 深色模式生成规则

前景主色 `accent`：浅色 → 深色时亮度提升，用「与白色混合 12%」近似。
底色 `canvas`：深色统一 `#1C1C1E`。
`tint`：深色用 `accent` 的 22% alpha 叠在 `#1C1C1E`（等价于把浅底换成深底 + 主色微光）。
`textOnAccent`：始终 `#FFFFFF`。

**实现方式**：`AppTheme` 里每套用 `UIColor { traits in ... }` 返回动态色，`Theme` 侧提供 `Theme.accent` 的运行时变体入口（见 §2.1）。

## 2. 数据模型（新增到 Shared，路径 `ios/Shared/Theme/`）

### 2.1 `AppTheme.swift`

```swift
/// 一套双色主题。
public struct AppTheme: Identifiable, Equatable, Sendable {
    public enum Preset: String, CaseIterable, Codable, Sendable {
        case ink, coral, indigo, violet, sky, pine
        public var displayName: String { ... }   // 墨黑 / 珊瑚 / ...
        public var brandNote: String { ... }     // 「ChatGPT 系」/「Claude 系」...
    }

    /// 主题 id。预设为 `Preset.rawValue`，自定义形象主题为 `"custom"`。
    public let id: String
    /// 显示名。
    public let name: String
    /// 品牌备注（预设才有）。
    public let brandNote: String?
    /// 主色（动态色，已按 §1.2 处理深浅色）。
    public let accent: Color
    /// 候选栏 / AI 条浅底。
    public let tint: Color
    /// 功能键底。
    public let tint2: Color
    /// 浅底上的主色深版文字。
    public let deep: Color
    /// 候选词副文字。
    public let sub: Color
    /// 键盘整体背景。
    public let canvas: Color

    /// 从预设构造。
    public static func preset(_ preset: Preset) -> AppTheme
    /// 全部预设（顺序即展示顺序）。
    public static var allPresets: [AppTheme]
    /// 默认主题（靛蓝）。
    public static var `default`: AppTheme
}
```

**颜色全部写死在这个文件里**（作为主题的唯一真相源），但必须与 `design/tokens.json` 的 `theme.*` 组逐项一致 —— `scripts/qa/consistency_check.py` 会比对（见 §6）。

### 2.2 `ThemeStore.swift`

```swift
/// 主题与自定义形象的持久化。
public final class ThemeStore: @unchecked Sendable {
    public static let shared = ThemeStore()

    /// 当前主题 id。
    public var currentThemeID: String { get set }
    /// 自定义形象（PNG Data，已裁剪到正方形）。
    public var customMascotData: Data? { get set }
    /// 自定义形象的显示名（用户可改，默认「我的形象」）。
    public var customMascotName: String { get set }

    /// 当前生效的主题（找不到就回退默认）。
    public var currentTheme: AppTheme { get }
}
```

存储键（追加到 `SharedStore.SharedStoreKey`）：
- `moyu.theme.current` = `"moyu.theme.current"`
- `moyu.theme.customMascot` = `"moyu.theme.customMascot"`
- `moyu.theme.customMascotName` = `"moyu.theme.customMascotName"`

> **无 App Group 时的降级**：`SharedStore` 已自动降级到 `UserDefaults.standard`，主题在键盘扩展里读不到宿主 App 存的值。**这不是 bug**，降级行为与心跳键一致：扩展用自己的 `UserDefaults.standard`，用户在键盘内设置页也能单独选主题。若将来开启 App Groups 自动打通，代码零改动。

## 3. 小形象（`KMMascot.swift`）

### 3.1 八个内置几何符号

| id | 名称 | 形态 |
|---|---|---|
| `whale` | 鲸尾 A | 上扬弧 + 分叉尾鳍（24×24 viewBox 单路径） |
| `whale2` | 鲸尾 B | 圆形鲸身 + 尾鳍剪影 |
| `spark` | 四角星 | 四尖角内凹星 |
| `star` | 五角星 | 经典五角星 |
| `moon` | 月牙 | 两圆相减 |
| `leaf` | 叶子 | 单侧弧叶 |
| `dot` | 圆点 | 正圆 |
| `chibi` | Q 版 | 圆头 + 两点眼 + 两腮红（唯一带「脸」的，纯几何可辩） |

**全部用 `Path` 手绘**，不用 SF Symbols（避免与系统图标语义冲突），不用任何外部 SVG 文件。

### 3.2 尺寸与位置

| 项 | 竖屏 | 横屏 |
|---|---|---|
| 符号视觉尺寸 | 22pt | 18pt |
| 角落格宽 | 30pt | 26pt |
| 距键盘右边距 | 5pt | 4pt |
| 与回车键间距 | 7pt | 6pt |
| 与键盘底边 | 0pt（与末行键底对齐） | 0pt |

**布局方式**：放在键区第 4 行（底行）**最右侧的独立格**里，`HStack` 里 `flex: 0 0 30`，**绝不用 `position: absolute` 浮在键上**（第一版就踩了这个坑，形象压在回车键上）。

**底行新的宽度分配（390pt 基准 / 384 内容宽）**：
```
123(42) + 🌐(42) + 空格(156) + ⏎(88) + 形象格(30) + 间距(6×4=24) = 384
```
即空格从 194 缩到 **156**。回车键保持 88。

> 若担心空格太窄：另一方案是形象格叠在回车键右上角内部（不占位），但会与回车键文字冲突，**不采用**。

### 3.3 状态

| 状态 | 表现 |
|---|---|
| 有形象 | 显示符号 / 自定义图片 |
| 无形象（用户关闭） | 该格留空（不占宽度，空格恢复 194） |
| AI 忙碌 | 形象轻微呼吸（opacity 0.6↔1.0，1.2s 循环），**Reduce Motion 时静态** |

## 4. 自定义形象导入（方案 D）

### 4.1 入口（两处）

1. **宿主 App**：`设置 › 主题与形象` 页（新建 `ThemeSettingsView.swift`）
2. **键盘扩展**：`ExtensionSettingsSheet` 新增「主题」分组（只能选预设 + 选择已导入的形象；导入要到宿主 App）

### 4.2 宿主 App 导入流程

```
[从相册选择] → PhotosPicker（iOS 16 `PhotosPicker`）
            → 拿到 Data → 用 PIL 等价逻辑做正方形裁切（居中裁切 + 缩放到 512×512）
            → 存 ThemeStore.customMascotData
            → 自动切到 "custom" 主题
            → 显示预览

[从剪贴板粘贴] → UIPasteboard.general.image → 同上
```

**技术要点**：
- `import PhotosUI` + `.photosPicker(isPresented:selection:matching: .images)`
- 需要 `NSPhotoLibraryUsageDescription`？—— **不需要**，`PhotosPicker` 是 out-of-process，无需相册权限。但**读剪贴板**在 iOS 16+ 会弹「允许粘贴？」，所以剪贴板入口要加说明。
- 裁切：`UIGraphicsImageRenderer` 画正方形，`contentMode = .scaleAspectFill`
- 存 512×512 PNG（约 100–300 KB），键盘侧读取后缩到 22pt 渲染

### 4.3 安全与边界

| 边界 | 处理 |
|---|---|
| 图片超大（>20 MB） | 拒绝并提示「图片太大，请选小一点的」 |
| 非图片 | 拒绝并提示 |
| 图片是纯色/全透明 | 允许，但提示「这张图看不出内容」 |
| 存放位置 | `SharedStore.setData`（无 App Group 时是 `UserDefaults.standard`，上限约 4MB，512 PNG 远低于） |
| 卸载 App | 数据一起清除（正常行为） |

## 5. 界面规格

### 5.1 宿主 App：`ThemeSettingsView`（新增）

路径：`ios/AIKeyboard/Settings/ThemeSettingsView.swift`

```
导航栏：主题与形象
├─ [预览区]  Card 320×212（等比缩小的键盘，实时应用选中主题）
├─ 主题  Section
│   └─ 2 列网格，6 个 ThemedThemeCell（色块 2 枚 + 名称 + 品牌备注 + 选中勾）
├─ 小形象  Section
│   ├─ 行：当前形象预览（22pt）+ 名称 + 「更换」
│   ├─ 行：从相册选择（PhotosPicker）
│   ├─ 行：从剪贴板粘贴
│   └─ 行：关闭小形象（Toggle）
└─ 说明 footnote：
    「形象可以放你喜欢的任何图片，只存在这台手机里，不会上传。」
    「想用网上的角色图？注意版权 —— 详见 docs/11」
```

### 5.2 键盘扩展：`ExtensionSettingsSheet` 新增分组

```
主题  Section
├─ 行：主题（显示当前主题名 + 6 个色点，点击展开选择器）
└─ 行：小形象（显示当前符号 / 自定义缩略图，点击展开 8 符号 + 自定义）
```

键盘内**只做选择**，不做导入（导入要在宿主 App，因为需要 PhotosPicker 全屏）。

### 5.3 主题选择器（键盘内展开）

横向 6 个圆形色块，直径 32，选中加 2pt 白环 + 2pt 主色外环。点击立即应用（`UIViewPropertyAnimator` 0.25s 过渡，Reduce Motion 直接切换）。

## 6. 验收

| 项 | 标准 |
|---|---|
| 主题 6 套可切换 | 键盘 4 处主色同步变化 |
| 主色只出现 4 处 | 逐屏截图核对，其余位置无主色 |
| 小形象不压回车键 | 与回车键间距 ≥ 6pt |
| 自定义形象 | 导入后键盘内 22pt 渲染清晰，不糊 |
| 深浅色 | 系统切深色后主色与底色都合理，无白底黑字刺眼 |
| 无 App Group 降级 | 键盘与宿主各自记住自己的选择，不崩溃 |
| 六闸门 | P0=P1=P2=0 |
| 一致性 | `Theme.accent` 等运行时覆盖不得让 `consistency_check.py` 报错 |

**一致性检查补充**：`scripts/qa/consistency_check.py` 新增一条 —— `design/tokens.json` 的 `theme` 组必须存在且 **6 套 × 7 个色值**齐全，并与 `ios/Shared/Theme/AppTheme.swift` 里的十六进制字面量逐项一致（缺失 P0，不一致 P1）。

## 8. 明确不做

- ❌ 不内置任何社区二创角色图（鲸鱼娘 / Claude娘…）
- ❌ 不做「主题商店」/ 在线下载（需要服务器，违背零后端）
- ❌ 不做动态壁纸式主题（键盘内存预算 30MB）
- ❌ 不做跟随 AI 服务商自动切换主题（用户没要求，且会让界面乱）
